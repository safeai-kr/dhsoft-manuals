# 번역본 캡처 눈 검토 지침 (언어별 에이전트 1명)

목적: 글자 교체 도구가 만든 번역본 화면 캡처를 한국어판과 나란히 보고, 모양이 틀어진 곳을 빠짐없이 찾는다. 고치는 건 이 단계에서 하지 않는다. 찾아서 적는다.

## 입력
- 검토 시트 폴더(명령에서 알려 준다). 시트 한 장 = 위 한국어판, 아래 번역본. 파일 이름은 `<분권>_<캡처>.png`.
- **시트를 한 장도 빠뜨리지 말고 모두 연다.** 한 장에 여러 문제가 있으면 모두 적는다.

## 찾을 것 (한국어판과 비교해서)
| 종류 | 이렇게 보이면 문제 |
| --- | --- |
| 가장자리 얼룩 | 모달·카드·버튼 가장자리가 한국어판은 일직선인데 번역본은 톱니처럼 들쭉날쭉하거나 색이 다른 네모가 보인다 |
| 지워진 선 | 입력칸·표·카드의 테두리 선이 글자 근처에서 끊겼다 |
| 색 뒤집힘 | 검은 버튼이 회색이 됐다, 흰 글자가 검은 글자가 됐다, 버튼 색과 다른 색 네모가 글자 뒤에 깔렸다 |
| 잘림·넘침 | 번역 글자 끝이 잘렸거나 버튼·칸·이미지 밖으로 나갔다 |
| 정렬 | 한국어판은 가운데 정렬인데 번역본은 왼쪽으로 쏠렸다(두 줄 안내문·아이콘 아래 글·버튼 안 글자) |
| 위치 틀어짐 | 버튼이 위 요소 중심에서 벗어났다, 글자가 칸 밖 다른 줄로 갔다 |
| 남은 한국어 | 번역본에 한국어가 읽히는 크기로 남아 있다 (모달 뒤 흐려진 배경 글·아이콘은 제외) |
| 빠진 글자 | 한국어판에 있던 글자가 번역본에서 사라졌다 (번역어 없이 빈 자리) |

문제가 아닌 것: 번역본 캡처 오른쪽에 흰 여백이 더 붙은 것(잘린 버튼을 완성하려고 일부러 넓힘) · 모달 바깥 흐려진 배경의 한국어 · 글자 크기가 조금 작아진 것(칸이 좁아 줄인 것, 85%까지는 정상) · 아이콘.

## 출력
`<출력 파일 경로>`(명령에서 알려 준다)에 JSON 배열로 적는다. 한 문제가 한 항목이다.

```json
[{"vol": "워크스페이스", "file": "s1_2_1.png", "kind": "가장자리 얼룩", "where": "모달 왼쪽 가장자리 y 150~360", "detail": "흐려진 배경 글자 자리가 연회색 네모로 덮여 톱니처럼 보임"}]
```

- `kind`는 위 표의 종류 이름 그대로. `where`는 위치를 픽셀이나 화면 요소 이름으로. `detail`은 한국어 한 문장.
- 확신이 서지 않으면 `kind` 앞에 `?`를 붙여 적는다. 빼지 않는다.
- 다른 파일은 고치지 않는다. 이미지도 고치지 않는다.
- 마지막에 본 시트 수, 문제 수를 한국어 두 줄로 보고한다.
