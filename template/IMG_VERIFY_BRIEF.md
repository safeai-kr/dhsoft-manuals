# 화면 캡처 한글 덩어리 검수 지침

목적: OCR이 찾은 한국어 글자 덩어리마다 「화면에 실제로 적힌 글」을 확정한다. 이 결과로 번역어를 그 자리에 다시 그린다.

## 입력
- `manuals/<분권>/img/loc/segments.json` — 덩어리 목록. `id`, `ocr`(OCR이 읽은 글), `file`(캡처 파일), `words`(픽셀로 나눈 낱말 경계 수), 좌표.
- `manuals/<분권>/img/loc/sheets/*.png` — 확인 시트. 덩어리마다 빨간 네모가 글자 자리이고, 왼쪽에 id와 OCR 글이 있다. **시트를 모두 눈으로 본다.** 흐려서 판단이 어려우면 `manuals/<분권>/ko/img/<file>`(원본 캡처)을 열어 문맥으로 읽는다.
- `manuals/<분권>/data/model.json` — 본문 글. 캡처 속 문구가 본문에도 나오면 본문 표기를 따른다.

## 출력
`manuals/<분권>/img/loc/verified.json` — 배열. **segments.json의 모든 id를 빠짐없이** 넣는다.

```json
[{"id": "s1_1_1_000", "ko": "임상시험 데이터 관리 플랫폼", "skip": false, "join_next": null,
  "bold": false, "align": "center", "role": "title", "truncated": false, "icon_lead": false, "note": ""}]
```

| 항목 | 뜻 |
| --- | --- |
| `ko` | 빨간 네모 안에 실제로 보이는 글. OCR 오독을 고친다. 아이콘을 글자로 읽은 머리글자(`A`, `L`, `29`, `•`, `&`, `◎` 등)는 뺀다. 네모 안의 영문·숫자·기호는 그대로 둔다(예: `5회`, `(WS → 프로젝트 → Site)`). 공백은 화면대로. |
| `skip` | 글자가 아니거나(아이콘·그림), 한글이 전혀 없거나, 같은 글이 겹쳐 두 번 잡혔으면 `true`. |
| `join_next` | 긴 문장이 줄바꿈되어 다음 덩어리로 이어지면 다음 덩어리 id. 문단의 첫 줄부터 마지막 줄 직전까지만 채우고, 마지막 줄은 `null`. 줄 순서는 id 순서와 같다. |
| `bold` | 주변 글보다 굵으면 `true`. |
| `align` | 글이 칸 안에서 가운데(버튼·탭·배지·표 머리)면 `center`, 오른쪽 끝에 붙어 있으면 `right`, 그 밖은 `left`. |
| `role` | `button`, `tab`, `badge`(상태 칩), `header`(표 머리), `status`, `label`(입력칸 라벨·메뉴), `placeholder`(입력칸 안 연한 예시글), `title`, `breadcrumb`, `text`(안내문·설명). |
| `truncated` | 글이 `…`로 끝나거나 칸에 잘려 있으면 `true`. |
| `icon_lead` | 빨간 네모 왼쪽 끝에 아이콘이 들어 있으면 `true`(아이콘 다음부터 글자). |
| `icon_trail` | 빨간 네모 오른쪽 끝에 아이콘(달력·×·화살표)이 들어 있으면 `true`(아이콘 앞까지 글자). 아이콘을 글자와 함께 지우지 않으려는 것이다. |
| `note` | 흐려서 추정한 글, 판단이 갈리는 곳을 짧게 한국어로. |

## 규칙
- OCR 글을 그대로 믿지 않는다. 반복되는 오독: 증→중, 출→존, 프로젝트→표무세르, `·`→`•`, `—`→`-`.
- 같은 화면 문구는 덩어리가 달라도 같은 글로 적는다.
- 글을 지어내지 않는다. 정말 읽을 수 없으면 OCR 글을 두고 `note`에 「판독 불가」라고 적는다.
- 다른 파일은 고치지 않는다. 파일 하나(`verified.json`)만 쓴다.
- 마지막에 `python3 -c` 로 JSON이 열리는지, id 수가 segments.json과 같은지 확인하고 결과(덩어리 수, skip 수, 고친 수)를 한국어 두 줄로 보고한다.
