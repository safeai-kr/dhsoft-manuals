# DH Soft · SMART EDC 사용자 매뉴얼

SMART EDC CRF 필드 타입별 사용자 매뉴얼(16개 분권)의 A4 HTML과 디자인 기준 문서를 모아 두는 저장소입니다.

## 배포 링크

**https://safeai-kr.github.io/dhsoft-manuals/**

GitHub Pages로 배포한 매뉴얼 목록 페이지입니다. 분권별·언어별 매뉴얼은 아래 「현재 올라간 것」 표의 링크로 바로 열 수 있습니다. 저장소는 비공개지만 배포 페이지는 링크를 아는 사람이면 누구나 볼 수 있습니다.

## 구성

```
prompt/
  SMART-EDC_매뉴얼_디자인_고정프롬프트.md   디자인·제작·검수 고정 규칙 (v105 기준)
manuals/
  <분권>/<언어>/
    SMART-EDC_사용자매뉴얼_CRF_<분권>_<언어>.html   A4 쪽 형태 HTML (PDF와 같은 템플릿)
    img/     화면 이미지 (300dpi 처리본), 헤더 이미지, 로고
    fonts/   Pretendard 고정 굵기 TTF (일본어는 Pretendard JP TTF), SIL OFL
    checks.json  자동 검사 결과 (한글 0 · 헤더 · 넘침 · 글꼴 · 참조 · 태그)
  <분권>/작업기록_다국어.md   다국어 작업 기록·결정 필요 사항
  <분권>/i18n/              번역 메모·교차 검수 기록
glossary/                   언어별 화면 표기 용어집 (전 분권 공통, 현재 전부 미확정)
```

영어·독일어·일본어판의 화면 캡처는 한국어 캡처의 글자 영역만 번역어로 바꾼 것입니다(현지화 UI 재캡처 아님). 좁은 칸은 글자가 많이 축소돼 있으며 `img/quality-manifest.json`과 작업 기록에 정리돼 있습니다.
