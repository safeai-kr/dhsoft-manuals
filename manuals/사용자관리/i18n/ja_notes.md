# 사용자관리 일본어(ja) 번역 메모

번역 기준: TRANSLATION_BRIEF.md

## 판단이 필요했던 곳

1. 상태 값 번역: 활성 → 有効, 비활성 → 無効, 초대 대기 → 招待待ち, 잠금 → ロック. 활성은 용어집에 이미 有効로 있어 그대로 맞췄다. 나머지는 일본어 UI 표기가 정해진 것이 없어 임의로 골랐다. [확인 필요] 실제 일본어 화면 문구와 맞는지 확인해 주세요.
2. 「잠금」은 「Lock」이라는 제품 용어와 연결된다. 원문 표기를 살리려고 본문은 ロック로 두었다.
3. 「이름」 열과 필드는 氏名으로 옮겼다. 일본 현장에서는 ユーザー名라고 부르는 곳도 있어, 실제 화면 표기를 정해야 한다.
4. 「종속 ProjectRole」은 「紐づく ProjectRole」로 옮겼다. ProjectRole은 코드 이름이라 Latin 그대로 두었다.
5. 「연구책임자」는 研究責任者로 옮겼다. 원문 어디에도 PI 약어가 없어 Latin 표기는 쓰지 않았다.
6. 「감사자」는 監査者로 옮겼다. 역할 이름으로 쓰인다면 AUDITOR와 함께 맞춰야 한다.
7. 예시 값 「연세대학교」는 延世大学校로 옮겼다. 일본에서 쓰는 공식 표기가 따로 있으면 알려 주세요.
8. 「확인 창」은 확인 다이얼로그를 뜻해서 確認ダイアログ로 옮겼다. 「창」은 전부 ダイアログ로 통일했다.
9. 「부제」는 화면 아래 제목을 가리킨다. 本文 안에서는 サブタイトル로 썼다.
10. 「역할별 대시보드」의 「거버넌스 위젯」은 ガバナンスウィジェット로 옮겼다. 화면에서 실제로 쓰는 이름인지 확인이 필요하다.

## 구조 확인

- 원문의 「」 인용은 모두 「」로 옮겼다. 화면 메시지 문구(“…”)는 같은 자리에 「」로 옮겼다.
- 「&gt;」는 원문에 있던 자리에만 썼다. (플랫폼 메뉴 &gt; 사용자 관리)
- 참조 번호(1.2, 1.3, 2.1, 2.2, 3.1, 3.2)와 태그 개수는 check_tr 검사에서 모두 맞았다.
