# 사용자관리 독일어(de) 번역 메모

확인이 필요한 곳과 판단한 곳을 정리했습니다. 번역문 안에는 표시를 넣지 않았습니다.

1. **실제 독일어 UI 문구를 모릅니다.** 상태 값(Einladung ausstehend, Aktiv, Inaktiv, Gesperrt), 버튼(Deaktivieren, Entsperren, Aktivieren), 필드명(Grund, Position / Abteilung)은 용어 기준으로 맞춘 번역입니다. 실제 화면 문구와 다르면 알려 주세요. 본문에 따옴표로 인용한 메시지(「Diese E-Mail ist bereits registriert」, 「Wird erneut gesendet…」)도 같은 이유로 확인이 필요합니다.
2. **「전체」 번역이 용어집과 다릅니다.** 용어집에는 「전체 → Voll」(레이아웃 너비)이 있어, 상태 필터의 「전체」는 「Alle」로 옮겼습니다. 두 뜻을 같은 단어로 둘지 정해 주세요.
3. **「잠금」과 「비활성」은 서로 다른 상태입니다.** 「잠금」은 Gesperrt, 「비활성」은 Inaktiv로 나눴고, 본문에서도 같은 단어를 씁니다.
4. **「소속 기관」은 Einrichtung으로 옮겼습니다.** 「기관 관리」 화면명은 「Einrichtungsverwaltung」으로 맞췄습니다. 기관관리 매뉴얼도 같은 단어를 써야 합니다.
5. **예시 기관명 「연세대학교」는 「Yonsei-Universität」로 옮겼습니다.** 공식 영문명 「Yonsei University」를 쓸지 결정이 필요합니다.
6. **「Workspace-Administrator」, 「ProjectRole」, 「Audit Trail」은 그대로 뒀습니다.** 제품 용어와 코드 식별자로 보고 원문 표기를 유지했습니다.
7. **문장 주체는 Sie(존칭)로 통일했습니다.** 「Nur Systemadministratoren」처럼 명령형이 필요한 곳도 존칭 기준으로 맞췄습니다.
8. **초대 링크의 유효 기간은 숫자 없이 옮겼습니다.** 원문에 기간 값이 없어서 「zeitlich begrenzt」로만 적었습니다.
