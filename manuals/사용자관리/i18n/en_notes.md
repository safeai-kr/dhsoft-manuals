# 사용자관리 영문 번역 메모 (en)

확인이 필요한 곳과 판단한 곳을 적었습니다. 번역문 안에는 표시를 넣지 않았습니다.

## 실제 UI 문구를 모르는 곳
- 버튼 「실행」은 `Run`으로 옮겼습니다. 실제 화면의 영문 버튼명을 확인해 주세요.
- 「자기 자신 불가」, 「이미 등록된 이메일입니다」, 「재발송 중…」은 영문 UI 문구가 없어 제가 정했습니다.
- 「서명 잠금」 배지는 `E-signature lock`으로 옮겼습니다. 화면에 같은 배지가 있으면 문구를 맞춰 주세요.
- 부제 「플랫폼 사용자 조회·상태 관리·초대」는 `Platform user lookup · Status management · Invitations`입니다.
- 「권한 관리」(프로젝트별 역할 배정 메뉴)의 영문명은 다른 권에서 확인되지 않았습니다. 정해진 이름이 있으면 알려 주세요.

## 판단으로 바꾼 곳
- 필터 옵션 「전체」는 `All`로 옮겼습니다. 용어집에 「전체」가 레이아웃 너비의 `Full`로 이미 있어서, 같은 낱말을 다른 뜻으로 쓰지 않으려고 따로 적었습니다.
- 예시 기관명 「연세대학교」는 `Yonsei University`로 옮겼습니다. 원문을 그대로 두어야 한다면 알려 주세요.
- 「소속 기관」과 「기관」은 모두 `Institution`으로 옮겼습니다.
- 「2.2 와 3.2」는 원문에 참조 표시(span)가 없어 그대로 두었습니다. 본문 안 표현은 「see 2.2 and 3.2」입니다.
- 「잠금 해제」와 「활성화」는 각각 `Unlock`, `Activate`로 옮겼습니다. 본문에 나올 때도 같은 단어를 씁니다.
- 「+ 신규 사용자 등록」 버튼과 절 제목 「신규 사용자 등록」은 같은 `Register new user`로 맞췄습니다.
- 비활성화 창의 「종속 ProjectRole」은 코드명이라 그대로 두고, 「Audit Trail」도 그대로 두었습니다.
- 「기관 관리」는 `Institution management`로 옮겼습니다. 기관관리 권의 제목과 같은 번역입니다.
