# 참여기관 권 영문 번역 메모 (en)

확인이 필요한 곳과 판단한 곳을 적었습니다. 번역 본문에는 표시를 넣지 않았습니다.

## 실제 영문 UI 문구를 알 수 없는 곳
- 메뉴 「참여 기관」은 Sites, 화면 제목 「참여 기관 목록」은 Site list로 옮겼습니다. 제품 화면에 다른 영문 명칭이 있으면 알려 주세요.
- 「기관 코드」(siteCode 계열이라고 원문에 적힌 값)와 「참여 기관 번호」를 서로 다른 항목으로 보고 site code, site number로 나눴습니다. 두 항목이 실제로 같은 값인지 확인해 주세요. 원문은 기관 코드가 이 프로젝트 안에서 부여한 번호(siteCode)라고 하고, 참여 기관 번호도 siteCode라고 적고 있습니다.
- 「Site 제한」 라벨은 Site restriction으로 옮겼습니다.
- 「이미 배정됨」은 Already assigned, 「해제됨」은 Released로 옮겼습니다.

## 판단한 곳
- 역할 이름은 원문 약어를 살리고 풀이를 괄호에 넣었습니다. 예: PI (principal investigator), CRC (research nurse), CRA (clinical research associate), DM (data manager), AUDITOR (auditor). 풀이 표기를 쓸지 확인해 주세요.
- 「모니터요원」은 CRA의 풀이로 보고 clinical research associate로 옮겼습니다.
- 「국가」 기본값 「대한민국」은 South Korea로 옮겼습니다.
- 「목록에 없는 기관은 요청으로 만든다」는 흐름은 원문대로 옮겼습니다. 승인 전에는 추가할 수 없다는 조건도 그대로 두었습니다.
- 「(1.2 유의사항 참조)」 등 권 안 위치 표기는 see Precautions in 1.2 형태로 풀었습니다.

## 원문에서 눈여겨볼 곳
- 원문 2.3 수정 화면의 노란 배너는 상태 이름을 PRJ 상태 = SETUP / TESTING으로 적고 있습니다. 다른 곳은 설정 중·테스트로 적혀 있어서, 영문도 SETUP / TESTING 그대로 두었습니다.
- 원문 「괄호 안이 현재 상태입니다」라는 설명은 배너 문구의 괄호 부분을 가리키는 것으로 읽고 그대로 옮겼습니다.
- 「역할 5종」 표는 원문에서 DM과 AUDITOR가 기관 배정 불가로 되어 있어 그대로 옮겼습니다.
