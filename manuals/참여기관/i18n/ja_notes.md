# 참여기관 권 일본어 번역 메모 (hy0909 검토용)

## 판단이 필요한 곳
- **책임연구자 · 연구책임자 → 責任研究者 (PI)**: 원문에 두 낱말이 섞여 있어(예: 「책임연구자명」, 「연구책임자(PI)」) 하나로 통일했습니다. 프로젝트 권과 같은 방식입니다.
- **참여 기관 → 参加施設, 기관 → 施設**: 프로젝트 권과 같은 말을 씁니다. Site는 영문 그대로 두었습니다.
- **연구간호사 → 研究看護師**: CRC 역할명 「CRC 研究看護師」로 옮겼습니다. 용어집에 없던 말이라 새로 넣었습니다.
- **임상연구모니터요원 → 臨床開発モニター**: 용어집의 기존 번역을 그대로 썼습니다.
- **사유 5자 이상 (해제 확인 창)**: 원문은 「5자 이상」입니다. 일본어 화면에서 글자 수를 세는 기준이 한국어와 같은지 확인이 필요합니다. 번역문에는 「5文字以上」으로 적었습니다.
- **상태 코드 SETUP · TESTING · ACTIVE · CLOSED · PRJ**: 원문처럼 영문 그대로 두었습니다. 화면 문구(설정 중 · 테스트 · 운영 중 · 종료)만 번역했습니다.

## 원문에서 눈에 띈 점 (그대로 번역함)
- 3.1 유의사항과 표 「역할 5종」 설명: 「연구책임자는 자기 기관만」이라는 규칙과 「PI 연구책임자」 표기가 같은 사람을 가리키는지 원문만으로는 확실하지 않습니다. 번역은 같은 역할로 보았습니다.
- 2.1 주의: 「참여 기관 번호를 비워 두면 기관 코드가 그대로 들어간다」는 설명과 「SITE-01 형식으로 직접 정할 수 있다」는 설명이 함께 있습니다. 원문 그대로 옮겼습니다.
- 3.1 안내 「Site 제한 역할만 배정할 수 있습니다」: UNIQUE 제약 문구는 원문의 괄호를 그대로 살려 「（UNIQUE制約）」로 옮겼습니다.
