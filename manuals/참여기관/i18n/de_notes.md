# 참여기관 권 독일어 번역 메모 (hy0909 검토용)

## 판단이 필요했던 곳
- **참여 기관 / 기관(Site)**: "참여 기관"은 teilnehmende Einrichtung(en), "기관"은 Einrichtung로 옮겼다. "Site"는 제품 용어라 영문 그대로 두었다.
- **연구자 → Forschungspersonal**: 원문이 "연구자"라고 쓴 곳 전부에 같은 말을 썼다. 배정 메뉴는 "Zuweisung des Forschungspersonals"다.
- **연구책임자(PI) / 책임연구자**: 둘 다 "verantwortlicher Prüfer"로 옮겼다. PI 표기는 원문대로 두었다.
- **역할 표 (5종)**: CRC 연구간호사 → Forschungspflegekraft, CRA 임상연구모니터요원 → klinischer Monitor, DM 데이터 관리자 → Datenmanager, AUDITOR 감사자 → Auditor. 역할 코드는 영문 그대로 두었다.
- **국가 기본값 (대한민국)**: 원문 "기본값은 대한민국"은 "Südkorea"로 옮겼다. 독일어 국가명 표기는 "Republik Korea"로 바꿔도 된다.
- **기관 유형 예시 (병원)**: "병원 등 유형"을 "zum Beispiel Krankenhaus"로 옮겼다. 실제 유형 목록을 확인하지 못했다.
- **종료 확인 배너**: 원문 "하위 참여 기관"은 "untergeordnete teilnehmende Einrichtungen"으로 옮겼다.
- **변경 이력 (p8s2i4)**: "현재 선택할 수 없습니다"는 "Derzeit nicht auswählbar"로 옮겼다.

## 원문에 대해 알아 둘 점
- **p7s2i6 (노란 배너)**: 원문은 "괄호 안이 현재 상태입니다"라고 쓰지만, 배너 문구에는 괄호가 없다. 원문 설명이 화면과 맞지 않는 것으로 보인다. 번역은 원문 설명을 그대로 옮겼으니, 원문이나 화면 중 하나를 확인해 주면 고친다.
- **PRJ 상태 = SETUP / TESTING (p7s2i6)**: 화면에 영문 상태명이 그대로 나온다면 독일어 상태명과 섞여 보일 수 있다. 화면 표기를 확인해 주면 맞춘다.
- **화면 문구 (큰따옴표 안)**: 배너, 안내문, 확인 창 문구는 한국어 원문을 옮긴 것이다. 실제 독일어 UI에 같은 문구가 있는지 확인되지 않았다.
- **SITE-01 예시 (p4s2i4)**: 원문 예시 형식을 그대로 두었다.
- **"배정" 버튼**: glossary 용어는 "Zuweisung"이지만 버튼 문구는 "Zuweisen"으로 옮겼다. 두 가지를 모두 glossary에 넣기 어려워 하나만 정리했다.

## 용어 정리
- 해제 = Zuweisung aufheben (버튼) / Aufgehoben (상태), 활성 = Aktiv, 종료 = Beendet, 보관 = Archiviert.
- 기관 관리 = Einrichtungsverwaltung (메뉴), 사용자 관리 = Benutzerverwaltung (메뉴). 프로젝트 권의 "권한 관리"는 Rechteverwaltung로 옮겼으니 두 권 메뉴명이 맞는지 확인이 필요하다.
- UNIQUE 제약은 UNIQUE-Einschränkung으로 옮기고 영문 표기는 그대로 두었다.
