Path Platform homeWorkspace management

Overview

A screen that manages the workspaces across the whole system. A workspace is a container for projects and the unit of user assignment, so to start a study, first create a workspace here.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Open it from Workspace management in the left menu.

Create new workspace — Creates a new workspace 1.2.

Summary — the total, active and inactive workspace counts, the total number of projects, and the total number of member assignments.

Search and filter — find workspaces by name or code, and narrow them by status and lead organization.

The subtitle states the scope of this screen — system-wide viewing, creation and deactivation.

Status cards — show first what needs attention, such as the distribution by organization, active workspaces with no members assigned, and active workspaces with no projects.

The table shows name, code, lead organization, number of projects, number of users, status and last entered. Select a name to go to its details 2.1.

The ⋯ at the right end of each row has View details · Assign users · Deactivate (for an inactive workspace, Activate). This menu is shown only to system administrators.

Precautions

Easily misunderstood behavior

  • • Only system administrators can create or deactivate workspaces. Workspace administrators can only view the workspaces assigned to them.
  • • Workspace administrators do not see the ⋯ menu at the right end of each row at all. It is not that the items are just disabled; the column is empty, so open details and user assignment by selecting the name directly 2.1 · 3.1.
Path Workspace managementCreate new workspace

Overview

Creates a new workspace. The three items marked with an asterisk must be filled in. After creation, you go straight to the details screen.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Workspace name — The name shown to users. You can change it later 2.2.

Code — A unique code that identifies the workspace. As the label notes, it cannot be changed after creation, so decide it carefully.

Lead organization — Select the organization that leads this workspace. If it is not in the list, register it first in Organization management.

Create — Creates the workspace.

Description — Optional. Writing what kind of study the workspace holds makes it easier to tell workspaces apart in the list.

Selecting outside the window or selecting Close discards your input.

Precautions

Must check Data corruption · Form cannot be completed

  • • The code cannot be changed after creation. Check your organization's code rules before you enter it.

Path Workspace managementWorkspace details

Overview

Shows all the information and to-dos for a single workspace together. You can see at a glance how far setup has progressed and what to do next.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Edit name and description — Edits the name and description 2.2.

Shortcut — Goes to the screen of the step shown as Next to-do.

Create project — Creates a project in this workspace 3.3.

User assignment management — Manages the workspace members 3.1.

Deactivate workspace — Changes the status to inactive.

The header shows the name, active status, code, lead organization, creation date and time, and the description.

Setup progress — Four steps: create workspace → assign users → create project → operation. Selecting each step card also takes you to that screen.

Summary — the total and active project counts, the total number of subjects, and the number of assigned users.

Precautions

Easily misunderstood behavior

  • • Even if the number of active projects is 0, there may still be projects overall. Projects in the setup stage (Setting up) are not counted as active.

Path Workspace managementWorkspace details

Overview

The bottom of the details screen has a member summary, an activity log and a deletion area. Deletion has strict conditions, so usually use deactivation instead.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

View all — Goes to the screen where you manage all the assigned users 3.1.

Delete workspace — Cannot be selected unless the conditions are met.

Assigned users is a summary, so only up to 5 people are shown.

Recent activity — Changes made in this workspace are listed from newest to oldest. You can see who changed what and when.

When deletion is blocked, the reason is shown. The screenshot is a case where deactivation has not been done first.

Precautions

Must check Data corruption · Form cannot be completed

  • • Deletion is possible only when the workspace is inactive and all of its projects are in the setup stage or there are none. Deletion permanently removes the workspace and everything under it, so it cannot be undone. Do not delete a workspace that has been in operation. Deactivate it instead.

Path Workspace detailsUser assignment management

Overview

A screen for assigning users to a workspace and removing them. Only users assigned here can take part in the projects of this workspace, so do this before assigning project roles.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Add user — Assigns a user to the workspace.

Change history — Looks up the records of assignments and removals.

Designate as administrator — Promotes that user to workspace administrator.

Remove — Removes the user's assignment from the workspace.

You can return to the higher-level screen from the path shown at the top.

The Role column is the user's position inside the workspace (member or administrator). It is separate from the role inside a project (such as researcher or monitor).

Access paths

  • • Workspace management list → ⋯ at the right end of the row → Assign users (system administrators only)
  • • Workspace details → User assignment management button
  • • Workspace details → the 2. Assign users step card in Setup progress
  • • Workspace details → View all in the assigned user summary
  • • Workspace dashboard → the same three places as above 3.2
  • • Researcher assignment screen in a project → the link shown when members are insufficient

Precautions

Must check Data corruption · Form cannot be completed

  • • If you remove a user from the workspace, that user's project roles are also cut off. Check whether the user has work in progress before you remove them.
Path WorkspaceWorkspace dashboard

Overview

The screen you move to from the Operation step of Setup progress, and also the screen every role lands on when entering the workspace. It has almost the same layout as the details screen on the administrator path, but the range shown depends on the viewer's permissions.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Shortcuts · Edit name and description · Summary are the same as on the details screen 2.1.

Create project — The same button as on the details screen 3.3.

User assignment management — The same button as on the details screen 3.1.

View change history — Cannot be selected without permission.

The path begins with Workspace ›, which differs from the Workspace management / of the administrator path. Check here which one you are in.

Setup progress is shown collapsed. Selecting it expands the four steps.

There is a search for projects in this workspace, and the number of participating organizations is shown in a column.

Access paths

  • • Select a workspace in the workspace list
  • • Continue (recently entered) or My projects on the platform home
  • • Select a workspace in the context switcher at the top of the screen
  • • Workspace dashboard in the left menu
  • • The guide screen you pass through when switching workspaces
  • • Workspace details → the 4. Operation step in Setup progress, or Shortcut

Precautions

Easily misunderstood behavior

  • • What you see depends on your permissions. Regular members cannot see the member list, Setup progress or recent activity, so do not judge that the screen looks different as an error.
Path Workspace dashboardCreate new project

Overview

Creates a project inside the workspace. A project is created with the Setting up status, and after setup is complete, you move it to the operation status.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Project code — A unique code that identifies the project. As the label notes, it cannot be changed after creation.

Project name — The name shown to users.

Study type — Select from options such as investigator-led.

Retention policy — Sets how long data is kept. The default is Standard.

Create project — Stays disabled until all the required fields are filled.

The header shows the target workspace and the initial status.

The usable characters and the length limit are shown below the code field.

Initial roles — Do not select any. When you create a project, the standard roles are generated automatically by the system.

Access paths

  • • Workspace details or dashboard → Create project button
  • • Workspace details or dashboard → 3. Create project step card in Setup progress
  • • The guide button shown in the project list area when the workspace has no projects

Precautions

Easily misunderstood behavior

  • • You cannot create a project in an inactive workspace. The relevant step and buttons in Setup progress are all locked.
Path WorkspaceWorkspace dashboard

Overview

When you try to enter an inactive workspace, the content is not shown and only a notice remains. This is not an incorrect access. It means that workspace is inactive.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Retry — Loads the page again. Use it after the workspace has been reactivated.

The notice “This workspace is in an inactive state.” is shown. The notice replaces the whole screen, so the list and summary are not visible.

Precautions

Easily misunderstood behavior

  • • Deactivation can be reversed. A system administrator can reactivate the workspace from the ⋯ menu on its row in the Workspace management list, and it is restored right away 1.1.
