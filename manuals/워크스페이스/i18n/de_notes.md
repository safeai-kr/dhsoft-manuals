# 워크스페이스 독일어 번역 메모

hy0909 님이 확인할 곳을 모았습니다.

## 확인이 필요한 곳

- **스크린샷 속 글자**: 그림은 원본 파일(img/orig)을 그대로 넣었습니다. 원본 화면은 한국어라서 그림 안 글자는 독일어 본문과 맞지 않습니다. 그림을 다시 만들지, 그대로 둘지 정해 주세요.
- **연구자 → Prüfer**: 원문의 연구자는 임상 현장의 investigator 뜻으로 보고 Prüfer로 옮겼습니다. Prüfarzt는 의사로 좁혀지는 말이라 피했습니다. 독일어 임상 현장에서 이 말이 맞는지 확인해 주세요.
- **화면 문구는 임시안**: 독일어 화면이 따로 없어서 버튼, 안내 문구, 상태 이름은 한국어 화면을 옮긴 말입니다. 예를 들어 「Dieser Workspace ist inaktiv.」, 「In Einrichtung」, 「Entfernen」이 그렇습니다. 실제 독일어 UI가 정해지면 맞춰 바꾸어야 합니다.

## 판단으로 정한 것

- **워크스페이스**: 독일어 Arbeitsbereich 대신 Workspace를 그대로 썼습니다. 제품 화면에서 영문 표기가 익숙하다고 보았습니다. 팀에서 Arbeitsbereich로 정한 말이 있으면 바꾸겠습니다.
- **생성 → Anlegen**: 버튼 「생성」과 「프로젝트 생성」은 Anlegen과 Projekt anlegen으로 옮겼습니다. 「추가」는 사용자 추가 버튼에서 Benutzer hinzufügen입니다.
- **해제 → Entfernen**: 워크스페이스에서 사용자 할당을 거두는 버튼입니다. 본문에서는 「할당을 거둡니다」처럼 풀어 썼습니다.
- **구성 현황**: 네 단계 카드 묶음은 Aufbaustatus, 마지막 단계 「운영」은 Betrieb로 옮겼습니다.
- **모니터요원**: Monitoring-Personal로 옮겼습니다. CRA 같은 약어는 그대로 두지 않고 풀어 썼습니다.
- **역할 구분**: 워크스페이스 안의 역할(멤버, 관리자)과 프로젝트 안의 역할을 따로 적었습니다. 원문의 구분을 살리기 위해서입니다.
- **빌드 단위 수**: 번역 키는 143개인데 빌드가 세는 단위는 142개입니다. 원인은 확인하지 못했습니다. 다만 모든 번역 문장이 HTML에 들어간 것은 확인했고, 빠진 문장은 없습니다.
