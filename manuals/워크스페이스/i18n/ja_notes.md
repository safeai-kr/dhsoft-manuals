# 워크스페이스 · 일본어(ja) 번역 메모

## 판단이 필요했던 곳
- **메타 편집 → メタ情報の編集**: 「メタデータ」보다 「メタ情報」가 뜻을 더 쉽게 전해 그렇게 했다. 설명·이름을 고치는 화면이라는 점을 살렸다.
- **구축 / 설정 중 / 운영**: 구성 현황의 단계 이름이다. 구축은 「構築」, 설정 중은 「設定中」, 운영은 「運用」로 했다. 기존 용어집에 없는 단어라 새로 정했다.
- **역할 → ロール**: 기존 용어집의 「ロール」를 그대로 썼다. 화면 열 이름이 「ロール」로 보이는지 확인해 달라.
- **모니터요원 → 臨床開発モニター**: 기존 용어집(임상연구모니터요원=臨床開発モニター)을 따랐다.
- **활성 / 비활성 → 有効 / 無効**: 기존 용어집의 「有効」를 따르고, 비활성 쪽은 「無効」로 맞췄다. 활성화・비활성화는 「有効化」・「無効化」다.
- **이어서 / 최근 진입 → 続きから / 最近のアクセス**: 플랫폼 홈의 이어서 목록과 최근 진입 기록을 가리킨다.
- **이어지는 화면 → 続く画面**: 3장 제목. 「次に続く画面」도 가능하지만 제목은 짧게 했다.
- **캡처는 → キャプチャは**: 원문이 화면 캡처 이미지를 가리키는 말이라 그대로 살렸다.
- **이 화면으로 가는 다른 길 → この画面へのほかの経路**: h3 제목. 여러 진입 경로를 뜻한다.
- **워크스페이스 › / 워크스페이스 관리 /**: 이동 경로의 구분 기호는 원문 그대로 두었다. 두 경로를 구분하라는 설명이라 기호가 바뀌면 안 된다.
- **물리 삭제 → 物理的に削除**: 되돌릴 수 없는 삭제라는 뜻을 살렸다.
- **⋯ 기호**: 행 오른쪽 메뉴 아이콘이라 원문 그대로 두었다.

## 확인이 필요한 곳(번역 문장 안에는 표시하지 않음)
- 「ワークスペース ›」로 시작하는 대시보드 경로 문구는 일본어 화면에서 실제 표시 형태가 다를 수 있다. 실제 화면과 대조해 달라.
- 구성 현황 단계 이름(構築・設定中・運用)이 실제 일본어 UI와 같은지 확인이 필요하다.
