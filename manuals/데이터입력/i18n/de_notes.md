# 데이터입력 분권 독일어 번역 메모

## 판단이 필요했던 곳

- **워크리스트**: 표지 부제에서 Worklist로 옮기고 영문 표기를 유지했다. 독일어 화면에서 "Arbeitsliste" 같은 말을 쓴다면 바꿔야 한다.
- **진행 · 전건완료 · 방문 실적 없음**(상태 필터): 「진행」은 Laufend, 「전건완료」는 Alle Eingaben abgeschlossen, 「방문 실적 없음」은 Ohne Besuchsnachweis로 옮겼다. 필터 칩에 들어가는 짧은 말이라 실제 화면 폭에 맞춰 줄일 수 있다.
- **등록 완료**(상태 값): 피험자 분권에서 「등록」은 Registriert로 옮겼는데, 이 분권의 「등록 완료」는 Registrierung abgeschlossen으로 옮겼다. 두 분권의 상태 이름을 맞추려면 하나로 정해야 한다.
- **연구책임자 · 연구간호사 · 임상연구모니터요원**: 역할 이름은 Hauptprüfer (PI), Studienpflegekraft, Klinischer Monitor (CRA)로 옮겼다. 독일어 화면의 역할 이름과 다를 수 있다.
- **방문 상태 배지 7종** : 「취소」는 "Abgebrochen", 「건너뜀」은 "Übersprungen"으로 옮겼다. 같은 한국어 낱말 「취소」가 버튼에서는 "Abbrechen"이므로, 버튼과 배지를 구분해 두었다.
- **Site**: 원문 그대로 Site를 쓰고 「내 Site 고정」은 Meine Site fixiert로 옮겼다. 피험자 분권의 「내 참여기관 고정」(Meine Einrichtung fixiert)과 표현이 다르므로 한쪽으로 맞추기를 권한다.
- **Cycle, Query, Window, DONE, SCHEDULED, NOT_CREATED 등**: 코드 값과 제품 용어라 영문 그대로 두었다.
- **Lock Override**: 원문 그대로 두었다.
- **「축이 다릅니다」**(다음 방문 열): 날짜의 기준(실제 날짜인지 계획 날짜인지)이 다르다는 뜻으로 읽고 "beruhen auf unterschiedlichen Grundlagen"으로 옮겼다. 원문 의도가 더 구체적이라면 알려 주면 고친다.
- **Q N 배지의 「0건이면 표시되지 않습니다」**: 원문대로 "Bei 0 wird nichts angezeigt"로 옮겼다.
- **해소 방식**: 독일어로 "Erledigungsart"로 옮겼다. 답변 카드 안에서 자동으로 정해지는 값이라는 설명을 원문대로 살렸다.
- **원자료 대조(SDV)**: 독일어로 "Quelldatenabgleich (SDV)"로 옮겼다. 피험자 분권과 같은 표기다.

## 확인이 필요한 용어

- 대시보드 위젯 이름(「오늘 예정 방문」 「방문 현황」)과 버튼 「방문 워크리스트 →」는 원문 표기를 독일어로 옮긴 것이고, 실제 독일어 화면과 대조하지 않았다.
- 화면 예시 값(혈압 필드, 허용 범위 표현)은 원문 그대로 숫자와 단위만 살렸다.
- 「5자 이상」 「0/3 완료 · 100%」 같은 예시 문구는 원문 숫자를 그대로 옮겼다.
