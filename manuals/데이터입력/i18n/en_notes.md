## 확인이 필요한 곳

- **「임시저장」 → Save draft**: 확정 저장이 아니라는 점을 살리려고 Save draft로 옮겼습니다. 실제 UI 버튼 영문명을 확인해 주세요.
- **「취소」 두 뜻**: 방문 상태 배지의 「취소」는 Canceled, 창의 취소 버튼은 Cancel로 나눴습니다. 같은 한글 단어가 쓰이는 곳이라 실제 화면과 맞는지 확인이 필요합니다.
- **「전건완료」 / 「전건 완료」**: 필터 이름과 상태 문구 둘 다 All completed로 옮겼습니다. 두 표기가 같은 상태를 가리키는지 확인해 주세요.
- **방문 상태 배지 7종 영문명**: 예정 · 진행 · 수행 · 미방문 · 건너뜀 · 취소 · 해당 없음은 제가 정한 말입니다. glossary에 없습니다.
- **「지연」 · 「임박」**: Overdue · Due soon으로 옮겼습니다. 허용 기간(Window) 경고 문구 그대로인지 확인이 필요합니다.
- **「오늘 예정 방문」 위젯 · 「방문 워크리스트」**: 대시보드의 실제 위젯 이름이 맞는지 확인해 주세요.
- **Query 카드 상태 「종결 대기」 → Awaiting closure**: 실제 표기를 모릅니다.
- **예시 값 「수축기혈압 · 이완기혈압 · 방문일」**: 화면 예시 입력란의 이름으로 봤습니다. 실제 예시 CRF 이름과 다르면 알려 주세요.
- **「Principal Investigator」**: 원문의 연구책임자·연구간호사·임상연구모니터요원을 역할 이름 그대로 풀어 썼습니다.

## 판단한 곳

- **「Site」**: 참여기관은 brief 규칙대로 Site로 두었습니다. 「내 Site 고정」은 Fixed to my Site입니다.
- **「메모」 → Memo**: 「참고」를 Note로 쓰는 고정 라벨과 겹치지 않게 Memo로 옮겼습니다.
- **「허용 기간(Window)」**: 원문의 Latin 「Window」는 괄호 안에 그대로 두었습니다.
- **「임시저장」 설명 「검증을 거치지 않고 감사 기록도 남지 않으므로」**: 원문 의미를 그대로 옮겼습니다. 가능하면 원래 기능 설명과 대조해 주세요.
- **「Save」 대 「Save draft」**: 저장과 임시저장을 같은 말로 두지 않도록 나눴습니다.
- **「입력 상태」 · 「품질 상태」 축 설명 표**: 원문 표를 그대로 옮기고 열 이름만 Axis / Display / Meaning으로 붙였습니다.
- **「SKIP」 「CANCEL」 「NA」**: 화면 코드 값은 그대로 두고 앞에 영문 뜻을 붙였습니다.
- **「5자 이상」**: at least 5 characters가 아니라 5 characters or more로 옮겼습니다. 조건 의미는 같습니다.
- **원문의 「Q N」 「DONE」 「SCHEDULED」**: 표시 문자 그대로 두었습니다.
