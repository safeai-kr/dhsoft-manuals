# AE지정 영문 번역 메모 (en)

화면 실제 영문 문구를 알 수 없어 정한 표현과 판단한 곳입니다.

## 판단한 곳

- **SAE 여부 → SAE flag, 중대성 여부 → seriousness flag.** 원문이 같은 필드를 두 이름으로 부릅니다. 지정 창과 목록은 「SAE 여부」, 서식 칸과 안내 글은 「중대성 여부」를 씁니다. 영문도 그대로 나눴습니다. 하나로 통일하려면 알려 주세요.
- **인지일 → Awareness date.** 실제 화면 영문 이름을 알 수 없습니다.
- **결과(서식 칸) → Outcome.** 사건의 귀결을 뜻하는 칸 이름입니다. 고정 라벨 「결과」(Result)와 다른 뜻이라 따로 옮겼습니다.
- **중증도 → Severity, 중대성 기준 → Seriousness criteria.** 원문이 중대성과 중증도를 다른 축으로 설명하므로 두 말을 섞지 않았습니다.
- **재판정 → re-flagging, 판정 → flag.** 용어집에 이미 있는 「재판정 → re-flagging」과 「자동 판정 → auto-flagging」을 따랐습니다. 그래서 본문도 judgment 대신 flag로 씁니다.
- **휴지통 → Trash can, 해제 → Remove, 변경 → Change, 서식 슬롯 → Form slot.** 행 액션의 영문 이름은 실제 화면 확인이 필요합니다.
- **과제 → study.** 「시스템이 채웁니다 (피험자·과제·기관 정보)」의 과제를 study로 옮겼습니다. 프로젝트와 같은 말인지 확인이 필요합니다.
- **자물쇠 → lock.** 아이콘 설명을 원문 그대로 옮겼습니다.
- **⛔, ⬆, –, →** 등 기호는 원문대로 둡니다.
- **Latin 값 BOOLEAN · SELECT · RADIO · DATE · DATETIME · CTCAE · Screening 등은 원문대로 둡니다.**

## 확인이 필요한 곳

- **p9s3h0 (표의 빈 머리글 칸).** 원문이 빈 칸이라 번역도 빈 칸으로 두었습니다. check_tr.py는 빈 값을 문제로 잡으므로 이 한 곳이 남습니다. 빈 칸을 그대로 둘지 정해 주세요.
- 버튼 「+ 행 추가」「일괄 등록」「지정 안 함」과 탭 「바인딩 개관」의 영문 라벨
- 「LAB 정상범위」「정상 · 낮음 · 높음」의 영문 표기가 실제 화면과 같은지
