## 2. 작업 흐름 (고정프롬프트 13절)

1. 한국어 데이터(`data/model.json`) → 번역 단위 추출(`template/build.py 숫자 ko --export` → `data/units_ko.json`). 화면 글자는 모두 id가 붙은 단위를 거치고, 번역이 없는 id가 있으면 빌드가 멈춘다.
2. 화면 이미지: Vision OCR(원본 + 2배 확대본 합침) → 픽셀 간격으로 글자 덩어리 분리·아이콘 분리·재OCR(`template/segment.py`) → 검수 시트로 OCR 교정(145개 중 40개 수정, `data/ocr_fixed.json`) → 수동 보정(`data/seg_overrides.json`).
3. 번역: 언어별 에이전트 1개씩(용어집 → 본문 → 이미지), 이어서 다른 에이전트가 원문과 1:1 교차 검수. EN 47건, DE 17건, JA 130건 수정(각 `i18n/<lang>_review.md`).
4. 이미지 글자 교체(`template/localize.py`): 한국어판과 같은 배율로 확대 → 확대본에서 배경색으로 지우고 Pretendard로 새로 씀. 크기·기준선은 원래 한글 잉크 높이로, 굵기는 원문을 400·500·700으로 그려 잉크 밀도가 가장 가까운 것으로, 정렬은 주변 빈 공간으로 판정. 같은 문단 줄은 크기·굵기·축소율 통일, 붙은 두 줄은 줄별로 다시 씀.
5. HTML·PDF·검사(`template/make.sh 숫자 <lang>`).

## 3. 이번 시범에서 고친 템플릿 문제

- 헤더 높이 가변(제목 두 줄이면 헤더 + 본문이 함께 내려감) — 독일어 절 제목에서 실제로 동작 확인.
- 이미지 묶음이 조금 모자라 쪽이 비면 캡처를 최대 85%까지 줄여 같은 쪽에 둠(표시 크기만 줄어 유효 dpi는 상승).
- 일본어: Chrome이 Pretendard JP OTF(CFF)를 Type3로 넣어 TTF로 변환(`template/otf2ttf.py`).
- 이미지 검사: 일본어 글자·아이콘을 한글로 잘못 읽는 오탐을 거르려고, OCR이 한글을 잡은 자리의 픽셀이 한국어판과 같은지 비교. 눈으로 확인한 아이콘 오탐 5건은 `data/ocr_false_positive.json`.
- 줄 간격 조정·다국어 자간(EN·DE −1%, JA 0)·일본어 줄바꿈(line-break: strict).

## 4. 결정이 필요한 것

1. **좁은 칸의 화면 글자(가장 큼).** 글자 교체 방식에서는 번역어가 원래 한국어 칸보다 길면 줄일 수밖에 없다. 넘쳐서 아이콘·테두리·옆 글자를 덮지 않게 최저 45%까지 줄였고, 축소 한계(버튼·라벨 65%, 긴 안내문 55%) 미만은 위 표와 같다. 특히 독일어는 45%로도 넘치는 칸이 많다(아이콘이 붙은 좁은 버튼·탭·배지). 해결 방법은 둘 중 하나다.
   - 해당 화면을 현지화 UI로 재캡처(가장 정확)
   - 언어별 승인 약어 사용(예: DE `Abschnitt hinzufügen` → `+ Abschnitt`) — 원문에 없는 축약이므로 승인이 필요
2. **원문 문제(번역이 아니라 한국어 원본 확인 필요)**
   - 3.5 `(아래 ‘라.’ 참조)`: 새 디자인에 `라.` 번호가 없어 가리키는 대상이 보이지 않음(EN·DE는 `D.`, JA는 영역 제목으로 옮김 — 통일 필요).
   - 3.4 캡처의 BMI 식 `{weight} / ({height} * 100)^2` ↔ 본문 3.5 예시 `{height} / 100`: 서로 반대.
   - 6.2 캡처의 value가 영문자 `O`인지 숫자 `0`인지.
   - 2.1 화면 안내 `ACTIVE 이후 PUBLISHED`의 정확한 의미(DE 검수에서 본문 2.1 해석을 따라 수정).
   - 화면 문구 `BE 권위 평가`의 의미(번역 3개 언어 모두 직역).
   - 3.5 목차 제목(`… 소수 자리`)과 헤더 제목(`… 소수 자리 · 제약`)이 다름.
3. **용어집 확정.** 3개 언어 용어집(`glossary/en·de·ja.json`, 139~170항목) 전부 `unconfirmed`다. 16개 분권 공통이므로 다음 분권 전에 확정이 필요하다. 특히 고정 문구(EN `Overview / Screen guide / Precautions`, `Must check / Easily misunderstood behavior / Note`, DE `Überblick / Bildschirmbeschreibung / Zu beachten`), EN `Validation`(탭) vs `verification`(SDV), JA `ルール`→`規則`, JA 개수 배지 `項目`.
4. **일본어 자간**: 고정프롬프트에 일본어 규칙이 없어 0으로 둠.
5. **독일어 1.1 첫 쪽**: 안내 영역이 두 줄로 늘어 이미지 묶음이 85%로도 들어가지 않아 개요만 있는 쪽이 생김(규칙대로 다음 쪽으로 넘김).

## 5. 확인하지 못한 것

- 실제 PDF 뷰어에서 마우스 드래그 복사(텍스트 추출 순서로만 확인).
