What is a Number field?

  • 1.1Adding a field and the property panel layout
Path CRF ManagementDataForm DesignEdit form

Overview

Number (NUMBER) is a field for entering numeric values. Use it for values that are compared by size or used in calculations, such as height, weight and test results. Unlike the text type, you can specify the allowed range, decimal places and unit, and the value can also be calculated automatically from other field values. For values that look like numbers but are not used in calculations (specimen numbers, phone numbers, etc.), Single-line text is a better fit — because leading zeros are lost.

Must check Data corruption · Form cannot be completed

  • • The type cannot be changed after the field is added. If you chose the wrong type, delete the field and add it again. (Only sub-items of table-type fields and field groups are an exception and allow a type change.)
  • • Do not use the Number type for values that need leading zeros. 007 is saved as 7. For values whose number of digits carries meaning, such as specimen numbers and subject numbers, it is safer to use Single-line text with a regular expression.
  • • The structure cannot be changed after publishing (PUBLISH). If changes are needed during operation, publish a new version.

Easily misunderstood behavior

This feature shows or hides this field depending on the value of another field. Use it for branching, such as accepting a number only when “Pre-survey info available = O”.

Note

Enable conditional display (condition) — When selected, the condition settings below appear.

A 🔗 eq badge appears above the field on the canvas to show that a condition is applied.

⚠ On-screen notice — “Hidden fields are exempt from required validation (affects data integrity).” The condition is evaluated by the system.

Reference field fieldKey — Another field in the same form on which the condition is based. Sibling fields in the same form are autocompleted, and you can also type a value not in the list.

value — The value to compare with.

Example at the bottom — fieldKey="gender" · operator="eq" · value="M" → show this field only when gender is M.

Precautions

Must check Data corruption · Form cannot be completed

  • • Setting a condition can exempt a field from required validation. While a field is hidden because the condition is not met, the form is completed with that field empty even if it is required. This is intended behavior, not a defect — requiring an item that is not shown would make the form impossible to complete.
  • • ⛔ Take care when applying conditional display to fields referenced by an auto calculation. If the condition is false, the referenced value is empty and the calculation result is also empty. Apply the same condition to the calculated field and the referenced fields so that they appear and disappear together. 3.4

  • • “Auto-save failed — manual save recommended” at the top of the capture is a notice shown when auto-save fails temporarily. In that case, press [Save] to save manually.

  • • If you enable the condition and leave the reference field blank, the condition is never met. Be sure to fill in all of ②–④. 6.2

Must remember

Must check Data corruption · Form cannot be completed

  • • Formulas do not know about units. A wrong conversion is not blocked and the wrong value is saved as is, so check the result with real values before publishing. 3.4
  • • Saving succeeds even if the calculation fails. With a missing reference · division by 0, only that field is left empty and no error is shown — check empty results regularly. 3.4
  • • Changing the unit does not convert existing values. Once values with different units are mixed in the same field, this cannot be undone. 3.3
  • • Do not use the Number type for values that need leading zeros. 007 becomes 7. 1.1
  • • Make validation messages match the actual settings. If only one side is set but the message states a range on both sides, users are misled. 4.3

Easily misunderstood behavior

  • • 0 is not an empty value. To distinguish it from not measured, use Allow not-measured declaration. 2.2 · 2.4
  • • min · max are the blocking axis. A feature that only warns about values outside the normal range is not on this screen. 3.1

Note

  • • Changing the fieldKey after saving breaks the link to existing data and also breaks formulas. 2.1
