# Lock 권 독일어 번역 메모 (hy0909 확인용)

## 판단이 들어간 곳
- **잠금 → Sperre, 해제 → Aufhebung, 적용 → anwenden**: 「Lock 적용」「Lock 해제」 버튼과 창 이름은 「Lock anwenden」「Lock aufheben」으로 옮겼다. 「Lock」은 제품 용어라 영어 그대로 두었다. 이름이 여러 권에서 다르게 나오지 않도록 다른 권의 「잠금」 번역이 있으면 맞춰 달라.
- **상세 메모**: 라벨은 「선택」인데 실제로는 3자(해제 창은 5자) 이상 입력해야 진행된다. 원문 설명을 그대로 옮겨 「optional」을 붙이고, 본문에서 실제 조건을 따로 밝혔다.
- **전자서명 → elektronische Signatur**: 서명 전용 비밀번호와 로그인 비밀번호가 다르다는 점을 본문에 그대로 옮겼다.
- **협정세계시 → koordinierte Weltzeit (UTC)**: 원문은 「Z」 표시를 설명하지만, 독일어 본문에는 UTC라는 약어를 함께 넣었다. 약어를 빼고 싶으면 알려 달라.
- **KST**: 원문 표기를 그대로 두었다. 독일 사용자에게 「한국 시간」이 더 잘 읽히는지는 판단이 필요하다.
- **기준일 → Stichtag**: 「당일 포함」은 「einschließlich des Stichtags」로 옮겼다.
- **전체 / 부분 배지 → Gesamt / Teilweise**: 용어집의 「전체」는 Voll이다. 이 배지는 잠금 범위를 가리키므로 Gesamt로 따로 정했다.
- **Patient Profile**: 원문이 영어 그대로라 영어를 유지했다. 독일어 화면에 다른 이름이 있는지는 확인하지 못했다.
- **Audit Trail, Query, Project Lock, Subject Lock, Interim Lock**: 제품 용어와 화면 영문 이름이라 그대로 두었다.
- **사유 구분 → Begründungskategorie, 해제 사유 → Grund der Aufhebung**: 적용 사유 목록과 해제 사유 목록이 다르다는 점을 본문에 밝혔다.
- **Subject → Subject**: 원문 표기 「Subject」를 유지했다. 피험자는 Proband로 옮겼다.

## 원문에서 확인이 필요한 곳
- 「p3s4i0」와 「p11s2i6」: 안내 문장이 현재 화면과 맞지 않는다. 원문이 「다음 단계에서 제공됩니다」, 「준비 중입니다」라고 적고 있으나 실제로는 기능이 이미 있다. 번역도 원문 그대로 옮기고, 안내가 실제와 다르다는 점을 본문에 적었다.
- 「p11s2i7」과 「p11s3i0」: 화면 예시 시각 2026-07-30 06:00 이 한국 시간 15:00이라는 계산이 맞는지 확인이 필요하다.
- 「p9s2i2」 등의 예시 숫자(대상 7건, 하위 Subject 7명, 피험자 4명)는 캡처 기준이다. 번역에서는 그대로 두었다.

## 화면 문구로 확인하지 못한 것
- 버튼, 탭, 배지, 열 이름은 모두 원문을 바탕으로 독일어로 옮겼다. 실제 독일어 화면 문구와 다를 수 있다. 용어집에 없던 것은 `i18n/glossary_de.json`에 넣었다.
- 「Project Lock 적용」「Project Lock 해제」 버튼 문구는 원문 설명을 따랐다.
