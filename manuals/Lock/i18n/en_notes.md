# Lock 영문 번역 메모 (en)

화면에 실제로 찍힌 영문 문구를 알 수 없어서 정한 표현과 판단한 곳을 적습니다. 실제 UI 영문 라벨과 다르면 알려 주세요.

## 먼저 확인할 곳

- **원문 안내문이 현재 화면과 맞지 않는 곳(1.2 하단 안내, 4.1 하단 안내).** 원문은 “Project HARD_LOCK·Project Lock 해제는 다음 단계에서 제공됩니다”라고 적었지만, 프로젝트 잠금 해제는 이미 제공되고 있습니다. 번역은 원문 그대로 옮겼습니다. 원문을 고칠지, 영문 안내를 고칠지 정해 주세요.
- **4.1 하단 안내의 「Audit Trail 화면에서 조회 예정」 문구.** 원문 안내는 준비 중이라고 하지만 Audit Trail 「Lock」 카테고리에서 이미 조회된다고 적혀 있습니다. 이것도 원문 그대로 옮겼고, 안내문이 예전 것이라는 설명만 붙였습니다.

## 판단한 곳

- **「Lock」과 「Subject Lock」, 「Project Lock」** 은 제품 용어로 보고 그대로 두었습니다. 「잠금」은 lock, 「잠그다」는 lock, 「해제」는 release로 옮겼습니다.
- **「Lock 상태 조회」 → Lock status view.** 화면 이름을 실제 UI 문구로 확인할 수 없습니다.
- **「피험자」 → subject.** 용어집의 기존 번역을 따랐습니다. 「Subject」는 원문에서 Latin 그대로 쓰는 말이라 그대로 두었습니다.
- **「HARD 가능」 배지 → “HARD available”.** 배지 글씨를 확인할 수 없습니다. 「HARD_LOCK」 코드 값은 그대로 두었습니다.
- **「전체」 / 「부분」(잠금 기준일) → All / Partial.** 「전체 잠금」(전체 데이터 잠금)은 whole-dataset lock으로, 「완전 잠금」(HARD_LOCK)은 full lock으로 나눴습니다. 두 말을 한 단어로 옮기지 않으려고 나눈 것입니다.
- **「잠금 기준일」과 「잠금 기준시점」.** 집계 표의 열은 날짜 기준이라 cut-off date, 이력 표의 열은 시각이라 cut-off time으로 옮겼습니다. 두 열이 같은 것을 가리키는지 확인해 주세요.
- **「협정세계시」 → Coordinated Universal Time.** 원문의 「Z」 표시와 9시간 차이 안내는 그대로 두었습니다. 영문에는 UTC 약어를 따로 넣지 않았습니다.
- **「서명 실행」 → Sign, 「전자서명으로 진행」 → Proceed to electronic signature.** 버튼 문구를 확인할 수 없습니다.
- **「재질의」 → Reopen.** Query 권(Query 매뉴얼)에서 쓴 「재질의(Reopen)」 번역과 맞췄습니다.
- **「원자료 대조」 → source data check (SDV).** 용어집의 기존 번역과 맞췄습니다.
- **사유 구분 목록(FREEZE · SOFT_LOCK · HARD_LOCK).** 「Interim Lock」은 원문 그대로 Latin으로 두었습니다. 「기타」는 Other, 「등」은 and so on으로 옮겼습니다.
- **「고유번호」 → unique ID.** 스크리닝번호와 함께 쓰인 말이라 피험자 고유 식별 값으로 보고 옮겼습니다. 실제 의미를 확인해 주세요.
- **「기준일」 포함 표현.** 「당일 포함」은 화면 문구 「Including that day」로 옮기고, 본문에서는 그 뜻을 풀어 썼습니다.
- **「상세 메모」와 최소 글자 수.** 원문이 「선택」이라고 적은 라벨을 「Optional」로 옮기고, 3자 이상·5자 이상 조건은 그대로 두었습니다. 라벨 문구가 Optional이 맞는지 확인해 주세요.
- **「프로젝트 잠금 · 집계」, 「대상 지정」 등 경로 이름.** 메뉴나 경로가 실제 영문 화면에 어떻게 찍히는지 확인이 필요합니다.
- **색 이름(빨간 배지·빨간 상자·초록 배지·파란 띠).** 원문 색을 그대로 설명하도록 옮겼습니다. 영문 매뉴얼에서도 색을 그대로 말하는 방식이 맞는지 확인해 주세요.
- **「Patient Profile」, 「Audit Trail」, 「Query」, 「Open Query」, 「CSV」** 는 원문에서 Latin으로 쓰인 말이라 그대로 두었습니다.
- **「KST」 표기.** 원문의 「일시 (KST)」를 Date & time (KST)로 옮겼습니다.
