# 배정 영문 번역 메모 (hy0909 검토용)

## 판단이 필요한 곳
- **공개 (맹검 단계)**: "Open-label"로 옮겼다 (p5s2i1). 원문은 "공개"만 있어 "Open" 또는 "Open-label" 중 정해 주세요.
- **환자 부적격 판정**: 원문이 "환자"라서 "Patient judged ineligible"로 옮겼다 (p10s2i1). 같은 화면의 다른 문장은 "피험자"를 subject로 옮겼으므로 통일할지 정해 주세요.
- **모니터요원**: 원문에 CRA라는 말이 없어 "monitors"로 옮겼다 (p3s3i0). 용어집의 CRA와 같은 사람인지 확인이 필요하다.
- **시스템 담당자 / 시스템 관리자**: 담당자는 "system owner", 관리자는 "system administrator"로 나눴다 (p3s3i0, p3s1i0 주변).
- **권한 관리**: 메뉴 이름을 "permission management"로 직역했다 (p3s3i0). 실제 영문 메뉴명과 다를 수 있다.
- **연구 관리 / 설계 항목**: "Study management > Assignment" 메뉴명은 직역이다. 실제 영문 메뉴명을 확인해 주세요.
- **맹검 용어**: "맹검"은 "blinding"으로 옮겼다. 맹검 단계 이름은 Single-blind · Double-blind · Triple-blind로 옮겼다.
- **번호 풀**: "Number pool"로 옮겼다. 원문 예시의 "pool" 표기와 맞춘 것이다.
- **해제 버튼**: "해제 실행"은 버튼 "Release"로, 섹션 제목 "배정 해제"는 "Release assignment"로 나눴다.
- **경고 문구**: "Terminal 상태 피험자는 배정 해제 불가"를 "Assignment release not allowed for Terminal status subjects"로 옮겼다. 실제 화면 문구와 다를 수 있다 (p10s3i0).
- **개요 지표 설명**: "2개 정의 · 8개 등록"의 "등록" 대상이 무엇인지 원문만으로는 알 수 없어 "2 defined · 8 registered"로 그대로 옮겼다 (p4s2i2).
- **"배정됨"과 "배정 완료"**: 둘 다 "Assigned"로 옮겼다. 지표 이름과 피험자 상태 값이 같은 영문이 되므로 다르게 할지 정해 주세요.
- **추가 업로드 문장**: "내려받아 올리십시오"는 "download and upload"로 옮겼다 (p7s3i0).

## 형식 규칙
- "+30건"은 "+30 numbers"로 옮겼다 (p7s2i0).
- 굵은 글씨 안의 "①②③④" 번호와 "Manual Override"의 대문자 표기는 원문 그대로 두었다.
- 시험군 "Arm"과 "Subject", "ENROLLED", "D-0007 → ARM_A", "randomNo/assignmentNo/stratum" 등 코드·Latin 표기는 그대로 두었다.
