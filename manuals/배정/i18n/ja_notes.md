# 배정 일본어(ja) 번역 메모

## 판단이 필요했던 곳
- **배정 → 割付**: 무작위 배정의 일본어 임상시험 표준어를 썼다. 배정 설정은 割付設定, 배정 수행은 割付実施, 배정 해제는 割付解除다. 제품 화면의 실제 표기가 다르면 전체를 바꿔야 한다.
- **맹검 공개 → 非盲検**: 원문 공개는 open label 뜻이라 非盲検으로 옮겼다. 공개라는 말을 그대로 쓰면 뜻이 흐려진다.
- **연구책임자 → 研究責任者(PI)**: 원문 PI 표기를 함께 적었다.
- **연구간호사 → 研究看護師**: 일본 현장 직무명 확인이 필요하다.
- **수정 → 編集**: 버튼과 본문 모두 編集으로 통일했다.
- **선택 두 가지 의미**: 버튼 선택은 選択, 목록 상태값은 任意로 나눴다.
- **Source(배정 방식) → Source (割付方式)**: 제품 표기 Source는 그대로 두고 괄호 안만 일본어로 바꿨다.
- **Blind Type, Internal, ENROLLED 등**: 원문 표기대로 두었다.
- **번호 풀 → 番号プール**: 파일 열 이름 randomNo, assignmentNo, armCode, stratum은 그대로 두었다.
- **외부 배정 시스템 → 外部割付システム**: 원문 그대로 옮겼다.

## 형식 처리
- 문장 끝 `<span class="ref">…</span>` 뒤의 마침표는 「。」로 바꿨다.
- 괄호는 반각 ()을 썼다.
- 원문에 없는 문장이나 설명은 넣지 않았다.

## 확인이 필요한 곳
- 연구간호사 직무명
- 割付 용어가 일본 측 화면 표기와 맞는지
- 非盲検(공개) 표기가 맞는지
