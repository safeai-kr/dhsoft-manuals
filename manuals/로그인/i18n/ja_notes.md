# 로그인 권 일본어 번역 메모 (ja)

## 실제 화면 문구를 확인해야 할 곳
- 버튼·상태 문구 「アカウントロック済み」(원문 「계정 잠금됨」): 일본어 화면에 실제로 쓰는 문구가 없어 새로 만들었다. 실제 화면과 다르면 바꿔야 한다.
- 링크 「パスワードをお忘れですか？」, 버튼 「再設定リンクを送信」「再設定完了」「ログイン画面へ」: 일본어 UI 문구 확인 필요.
- 표시 토글 「言語表示」(원문 「언어 표시」): 원문도 선택 불가 안내라서 라벨 자체의 일본어 표기가 맞는지 확인 필요.
- 로그인 상태 유지 「ログイン状態の維持」: 체크박스 라벨 문구 확인 필요.

## 판단이 들어간 곳
- 「착지 화면」은 「遷移先画面」으로 옮겼다. 로그인 후 처음 열리는 화면이라는 뜻이다.
- 「재설정 요청」은 장 안의 소제목과 본문 목록에서 모두 「再設定の要求」로 통일했다.
- 「이메일」 라벨은 용어집대로 「メール」, 문장 안에서는 「メールアドレス」를 썼다.
- 「비밀번호」는 「パスワード」로 통일했다. 전자서명 비밀번호는 「電子署名パスワード」다.
- 「입력 검사 ① 조건 미충족 · 불일치」 제목처럼 원문 가운데 점(·)은 그대로 두었다.
- 「2장」 참조는 「第2章」, 「1.4」 같은 숫자 참조는 원문 위치 그대로 두었다.
- 경고 문구는 원문 「」를 일본어 「」로 그대로 옮겼다.

## 제목·문구 대조
- 「로그인 성공 (플랫폼 홈)」은 h2 제목과 본문 어디서도 「ログイン成功（プラットフォームホーム）」로 같다.
- 빌드 결과: 26쪽. check.py는 모든 항목 통과(pass: true).
