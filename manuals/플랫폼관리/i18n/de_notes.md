# 플랫폼관리 독일어 번역 메모

hy0909 님이 확인할 곳을 모았습니다.

## 확인이 필요한 곳

- **스크린샷 속 글자**: 그림은 원본 파일(img/orig)을 그대로 넣었습니다. 원본 화면은 한국어라서 그림 안 글자는 독일어 본문과 맞지 않습니다. 그림을 다시 만들지, 그대로 둘지 정해 주세요.
- **파일명 규칙**: 본문의 `login-history_연월일T시분.csv`는 `login-history_JJJJMMTTThhmm.csv`로 옮겼습니다. 독일어 날짜 표기(JJJJ 연도, MM 월, TT 일, hh 시, mm 분)를 따랐습니다. 실제 내려받기 파일명이 다르면 알려 주세요.
- **「전체」 충돌**: 공유 용어집에서 「전체」는 너비 옵션이라 Voll로 되어 있습니다. 여기서는 카테고리 탭 이름이라 Alle로 옮겼습니다. 두 뜻이 다르므로 이대로 두었습니다.
- **화면 문구는 임시안**: 독일어 화면이 따로 없어서 버튼, 안내 문구, 상태 이름은 한국어 화면을 옮긴 말입니다. 예를 들어 「Gesamt-Export nicht unterstützt」, 「nicht angewendet」, 「Aktuelle Ergebnisse」가 그렇습니다. 실제 독일어 UI가 정해지면 맞춰 바꾸어야 합니다.

## 판단으로 정한 것

- **운영 이력 / 변경 이력**: 운영 이력은 Betriebshistorie, 변경 이력은 공유 용어집의 Änderungshistorie로 나눴습니다. 두 말이 헷갈리지 않게 하려는 뜻입니다.
- **대상 열**: 「대상」은 Objekt로 옮겼습니다. 「대상 종류」는 Objekttyp입니다.
- **undefined**: 원문에 있는 undefined는 표시 결함이 맞으므로 번역하지 않고 그대로 두었습니다.
- **상세 열과 상세 보기**: 열 이름 「상세」는 Details, 화면 이름 「상세 보기」는 Detailansicht로 옮겼습니다.
- **말투**: 설명 항목은 원문처럼 명사구와 짧은 문장으로 두었습니다. 지시는 Sie 형식으로 썼습니다.
- **빌드 단위 수**: 번역 키는 156개인데 빌드가 세는 단위는 155개입니다. 원인은 확인하지 못했습니다. 다만 모든 번역 문장이 HTML에 들어간 것은 확인했고, 빠진 문장은 없습니다.
