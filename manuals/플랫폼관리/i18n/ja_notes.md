# 플랫폼관리 · 일본어(ja) 번역 메모

## 판단이 필요했던 곳
- **잠김 → ロック**: 원문은 "잠김" 상태 값이다. 일본어 UI에 쓸 확정 단어가 없어 카타카나 「ロック」로 했다. 실제 제품 일본어 UI가 다르면 알려 주면 바꾼다.
- **유형 vs 타입**: 원문에 "유형(SYSTEM 그룹)"과 "타입(설정값)"이 따로 있다. 코드 그룹의 유형은 「種類」, 설정값의 타입은 기존 용어집의 「タイプ」로 나눴다.
- **방문 미방문 사유 → 来院・未来院の理由**: 뜻을 살려 풀어 쓴 표현이다. 실제 일본어 화면 명칭이 정해지면 맞춘다.
- **시드한 → 初期データとして投入された**: 시스템 초기 데이터라는 뜻으로 풀었다.
- **export 표기**: 「全件 export 非対応」, 「EXPORT」 카테고리명은 원문이 영문 그대로라 Latin 표기를 유지했다.
- **CSV/Excel 내보내기 → CSV/Excelエクスポート**: 버튼명은 「エクスポート」로 통일했다.
- **보기 → 表示, 닫기 → 閉じる, 취소 → キャンセル**: 일본어 IT 화면의 일반적인 표기를 썼다. 기존 용어집에는 없었다.
- **(확대) → （拡大）**: 그림 설명 끝의 확대 표시를 같은 뜻으로 옮겼다.
- **파일명 패턴 login-history_연월일T시분.csv**: 파일명 자체는 그대로 두고, 날짜 부분 설명만 「年月日T時分」로 옮겼다.

## 원문 그대로 둔 것
- 「대상」 열의 **undefined**: 원문이 표시 결함이라고 밝힌 부분이라 번역문에도 그대로 남겼다. 고쳐진 뒤에는 원문과 함께 지워야 한다.
- 🔒 이모지, ⋯ 기호, 설정 키·코드·Audit Trail 같은 Latin 토큰은 그대로 두었다.

## 확인이 필요한 곳(번역 문장 안에는 표시하지 않음)
- 원문 p9s2i1의 「전수 export 미지원」은 일본어 화면 문구가 확정되지 않았다. 「全件 export 非対応」로 옮겼다.
- 원문 p3s2i8의 「잠김」 상태 설명과 p3s3i0의 영향 범위 안내는 실제 동작 문구와 맞는지 한 번 더 확인해 주면 좋겠다.
