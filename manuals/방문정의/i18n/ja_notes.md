# 방문정의 일본어(ja) 번역 메모

## 판단이 필요했던 곳
- **방문 → 来院**: 기존 용어집의 방문일(来院日), 방문 창(来院ウィンドウ)과 맞췄다. 임상 현장에서 訪問을 쓰는 곳이 있으면 전체를 바꿔야 한다.
- **연구책임자 → 研究責任者(PI)**: 원문에 PI가 함께 적혀 있어 그대로 병기했다.
- **연구간호사 → 研究看護師**: 일본 현장에서 쓰는 직무명이 다를 수 있다. 확인이 필요하다.
- **모니터요원 → 臨床開発モニター**: 기존 용어집의 임상연구모니터요원 표기와 맞췄다.
- **수정 → 編集**: 버튼과 본문 모두 編集으로 통일했다. 기존 용어집의 편집과 같다.
- **선택 두 가지 의미**: 다중 선택 버튼은 選択, 연결 상태 값(OPTIONAL)은 任意로 나눴다. 같은 한국어 낱말이 두 뜻으로 쓰여 헷갈리지 않게 한 처리다.
- **Plan 미리보기 → Plan プレビュー**: 제품 표기 Plan을 그대로 두었다.
- **연결 조회/수정 → 紐付けの照会/編集**: 紐付け는 연결의 뜻으로 골랐다. 제품 화면 표기가 따로 있다면 바꿔야 한다.
- **Window Before/After (일) → (日)**: 원문 표기 형식을 유지했다.

## 형식 처리
- 문장 끝 `<span class="ref">…</span>` 뒤의 마침표는 일본어 문장 부호 「。」로 바꿨다. 글자 정보는 같다.
- 괄호는 반각 ()을 썼다. 용어집의 기존 표기와 맞춘 것이다.
- DRAFT, PUBLISHED, ACTIVE, SETUP, Visit Type, Anchor Type, Offset Days, Repeating 등 제품 고유 표기는 그대로 두었다.

## 확인이 필요한 곳
- 연구간호사의 일본어 직무명
- 紐付け(연결) 용어가 실제 일본어 화면과 맞는지
