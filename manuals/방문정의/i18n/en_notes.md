# 방문정의 영문 번역 메모 (hy0909 검토용)

## 판단이 필요한 곳
- **다중 선택**: 용어집에 "다중 선택 = Multiple choice"로 되어 있어 연결 수정 화면의 다중 선택 모드도 "multiple choice mode"로 옮겼다 (p9s1i0, p9s2i2, p9s2i6). 버튼 이름으로는 "Multi-select"가 더 자연스러울 수 있다. 용어집을 바꿀지 정해 주세요.
- **선택**: 버튼(다중 선택 켜기)은 "Select", 연결 상태 값은 "Optional"로 나눴다. 원문에서는 같은 단어라 구분이 필요했다.
- **모니터요원**: 원문에는 CRA라는 말이 없어 "monitors"로 옮겼다. 용어집의 CRA(임상연구모니터요원)와 같은 사람인지 확인이 필요하다.
- **화면 이름 직역**: "연구 관리 > 방문 정의" 메뉴명은 "Study management > Visit definition"으로, "설계 버전 관리"는 "design version management"로 옮겼다. 실제 영문 UI 이름과 다르면 알려 주세요.
- **구축 파일**: 정렬값 기본값을 가져온 파일을 "build file"로 옮겼다 (p10s3i0). 실제 파일 이름이 있으면 맞춰야 한다.
- **사전동의/서명**: "informed consent/signature"로 옮겼다 (p5s2i1).
- **전체**: 시험군 필터 탭은 "All"로 옮겼다 (p3s2i8). 용어집에는 "전체 = Full"(레이아웃 너비)이 있어 같은 한국어에 다른 번역이 된다. 탭 이름이라 "All"이 맞다고 판단했으니 확인해 주세요. 그래서 용어집 파일에는 넣지 않았다.
- **연결 조회 문장**: "값이 바뀌지 않으며"를 "so nothing changes"로 옮겼다 (p8s1i0).

## 형식 규칙
- 캡션의 "(확대)"는 "(enlarged)"로 옮겼다.
- "CRF 2건 연결 (v1: 2건)"은 "2 CRFs linked (v1: 2)"로 옮겼다 (p6s2i7).
- 원문 굵은 글씨 안의 앞 공백(p6s1i0, p8s1i0)은 그대로 두었다.
- 시험군 "Arm"은 원문대로 Latin으로 두었다.
