パス プロジェクトダッシュボード来院定義管理

概要

研究スケジュールに入る来院を定義する画面です。左が来院をまとめるVisitGroupのツリーで、右が選択した来院の詳細です。ここで定義した来院は被験者ごとに展開されて来院タイムラインになるため、被験者登録より先に終えておく構築作業です。

結果 すぐ上の設定で変わる位置
参考

+ 新規 VisitGroup —来院をまとめる単位を新しく作成します 1.2。

ツリーの+は、そのグループに来院を追加し、鉛筆はグループ自体を編集します。来院はドラッグして順序を入れ替えられます。

CRF Visit Matrix — 来院ごとにどのCRFを受けるかを紐付ける画面に移動します 3.1。

編集 — 選択した来院の定義値を編集します 1.3。横の無効化は、発行済みの来院を取り下げる手段で、削除の代わりに使います。

発行 · 新しいバージョン作成 — 定義のバージョンを扱います 2.1。

左メニューの研究管理 > 来院定義が常時の入口です。設計バージョン管理の作業リストからも入ることができます。

移動経路はダッシュボード / 来院定義管理です。

Plan プレビュー — 定義した来院が実際に何日目に入るかを事前に確認します 2.2。

共通 / 全体タブ — 試験群 (Arm) ごとのフィルターです。共通は、すべての試験群が一緒に使う来院です。

発行済みのバージョンですの案内 — 構築段階では発行後も編集が可能ですが、削除の代わりに無効化を使います。

詳細の主な値はVisit コード · Visit 名 · Visit Type · Anchor Type · Offset Days · Repeating · Window Before/After · 許可する被験者の状態です 1.3。

バージョン選択 — その来院のバージョンを切り替えます。横のバージョン表示で、バージョンごとの違いを確認します。

詳細の上部にバージョン番号と発行状態のバッジが並んで表示されます。

注意事項

誤解しやすい動作

  • • この画面に入れるのは、データ管理者(DM)とワークスペース管理者だけです。研究責任者(PI)・研究看護師・臨床開発モニターは、照会目的であっても入ることができません。来院計画を確認する必要がある場合は、被験者の来院タイムラインまたはPlanプレビューの結果を共有してもらってください。
パス 来院定義管理新規 VisitGroup 追加

概要

来院をまとめる単位を作成します。スクリーニング段階 · 治療段階のように研究スケジュールの大きな区切りをグループにし、その中に個別の来院を入れます。周期治療のように同じ来院が繰り返される研究では、Cycle 繰り返しをオンにして一度だけ定義し、周期の数だけ展開します。

Study Arm * — 現在のタブの試験群が自動で選択されます。共通にすると、すべての試験群が一緒に使います。

Visit Group コード * — 英字・数字・アンダースコア・ハイフンのみ使用でき、作成後は変更できません。

Visit Group 名 * — 画面に表示される名前です。

Cycle 繰り返しを有効化 — オンにすると1 Cycle 周期(日数)の入力が必要になり、最大 Cycle 数は任意入力です。

作成 — 必須の3項目がすべて入力されると選択できます。

Study Arm の案内 — 現在のタブの試験群が既定で選ばれており、変更することもできます。

コード欄の下に、使用できる文字と変更できないことが併せて案内されます。

Cycle の説明 — 周期治療で同じ来院を繰り返す場合に使います。

必須項目が空欄の場合は、下に何を入力すべきかが案内されます。

ウィンドウ上部のArm: 共通 — 今どの試験群のタブで作成しているかを示します。

必須確認 データ破損 · フォーム完了不可

  • • VisitGroup コードは作成後、最後まで変更できません。グループの削除も設定中(SETUP)の段階でのみ可能で、テスト段階ではすでに禁止されています。研究スケジュールの構造を確定してから作成してください。
パス 来院定義管理定義の編集

概要

選択した来院の定義値を編集します。Visit コードとVisit Typeは背景がグレーでロックされており、それ以外は構築段階で自由に変更できます。保存するとツリーと詳細がすぐに更新されます。

画面説明

設定 直接操作する位置
結果 すぐ上の設定で変わる位置
参考

Visit 名 — 画面に表示される名前です。

Anchor Type — 日付を数える基準点です。事前同意/署名を基準にすると、その日付がDay 0になります。

Offset Days (anchor 基準) — 基準日から何日目かです。0の場合は基準日当日です。

Repeating — 同じ来院が繰り返されるかどうかです。

Window Before/After (日) — 予定日の前後で何日まで許容するかです。来院タイムラインの(-N/+N)表示がこの値です。

被験者状態の制限 — 初期設定は制限なしです。特定の状態の被験者にだけCRFを作成させたい場合は、下の10種類の状態から選択します。

保存 — 変更を反映します。横のキャンセルは変更を破棄します。

Visit コードは「作成後は変更できません」として、ロックされています。

Visit Typeは「プロジェクトの SETUP 段階でのみ変更可能」のため、テスト段階ではロックされます。

Window AfterはWindow Beforeと対になっています。

状態制限の案内 — 「選択した状態の被験者だけが、この来院のCRFを新たに作成できます。… すでに入力された記録の訂正は制限されません。」

注意事項

必須確認 データ破損 · フォーム完了不可

  • • 運用(ACTIVE)に移行すると、定義の編集もバージョンの新規作成もすべてできなくなります。その時点で残るのは発行済みの来院の無効化だけなので、日程設計は構築段階(設定中・テスト)で確定しておく必要があります。

バージョン管理

  • 2.1新しいバージョンの作成と発行
  • 2.2Plan プレビュー
パス 来院定義管理バージョン

概要

発行済みの定義を修正する必要がある場合は、新しいバージョンを作成します。新しいバージョンはDRAFTとして作られ、発行して初めて被験者の来院に反映されます。その上の 改訂版発行前の確認カードで、発行によって何が変わるかを事前に確認できます。

画面説明

設定 直接操作する位置
結果 すぐ上の設定で変わる位置
参考

バージョン選択 — その来院のバージョンを切り替えます。キャプチャではv2 (DRAFT)です。

バージョン表示 — バージョンごとの違いを確認します。

新しいバージョン作成 — 発行済みのバージョンからのみ選択できます。すでにDRAFTがある場合は薄く表示されます。

発行 — DRAFTを発行します。発行の権限は別にあるため、編集だけができるユーザーもいます。

削除 — DRAFTのバージョンを削除します。発行済みのバージョンは、削除の代わりに無効化します。

編集 — DRAFTの定義値を編集します 1.3。

改訂版発行前の確認 — 発行前に確認すべき事項をまとめて表示します。✓ は確認済み、ℹ は把握しておくべき事項です。

「CRF 2件を紐付け (v1: 2件)」 — 新しいバージョンに紐付いたCRFの件数と、旧バージョンとの違いです。0件の場合は、紐付けをコピーするボタンも併せて表示されます。

バージョンバッジv2と、ステータスバッジDRAFTが並んで表示されます。

グループ・Arm・コードはバージョンが変わっても同じです。同じ来院の別の版だからです。

注意事項

必須確認 データ破損 · フォーム完了不可

  • • 発行しないと、被験者に来院は1件も作成されません。システムは発行済みの定義だけを被験者の来院に展開するため、DRAFTしかない状態では、被験者画面は単に「来院なし」と表示されます。定義はあるのに発行済みのものがない場合は、この画面が警告を表示するので、必ず確認してください。
パス 来院定義管理VisitPlan プレビュー

概要

定義した来院が何日目に入るかを、事前に計算して表示します。実際の被験者データは使わず、定義値だけで描画するため、登録前に日程設計を確認する用途です。

画面説明

設定 直接操作する位置
結果 すぐ上の設定で変わる位置
参考

閉じる — ウィンドウを閉じます。ウィンドウの外をクリックしても同じです。

説明 — 登録された来院定義を試験群ごとに展開して表示する、という意味です。

anchor=Day 0 相対日 · 設計時点の投影 (実被験者とは無関係) — 基準日を0日として計算し、周期グループは周期ごとに展開されます。

試験群タブ — 試験群が複数ある場合は、ここで切り替えて確認します。

1行が来院1件です — D0(基準日からの日数) · コード · 名前 · 種類 · 基準 · ±0/0(許容誤差)の順に並びます。

注意事項

誤解しやすい動作

  • • ここに表示される日付は、基準日を0日とした相対日数であり、カレンダーの日付ではありません。実際の日付は被験者ごとに、事前同意日などの基準日が異なるため、それぞれの被験者の来院タイムラインで計算されます。

パス 来院定義管理CRFマッピング

概要

来院ごとにどのCRFを受けるかを紐付ける画面です。縦が来院、横がCRFの表で、交差点のチェックが紐付けです。初めて開くと紐付けの照会モードになっており、値は変わりません。紐付けを変更するには編集を押します 3.2。

画面説明

設定 直接操作する位置
結果 すぐ上の設定で変わる位置
参考

編集 — 紐付けを変更できるモードに切り替えます 3.2。

フォーム順序 — 来院ごとのCRFカードの順番を決めます 3.3。

見出しの紐付けの照会バッジが現在のモードです。

フォーム列の並べ替えチップ — 現在の列が、どの来院のカード順で並べられているかを示します。×で解除します。

列見出し — CRFコード · 名前 · バージョンです。DRAFTの列はグレーで表示され、紐付けできません。先にそのCRFを発行する必要があります。

行見出し — 来院名 · 種類 · コードです。下の選択ボックスで、その来院の定義バージョンを選びます。

交差点のチェックが紐付けです。紐付けされたセルを選択すると、右側にそのCRFの項目が表示されます。

下の凡例 — 必須 · 任意 · 未マッピングの3種類と、並べ替えの基準が書かれています。

注意事項

必須確認 データ破損 · フォーム完了不可

  • • CRFは発行(PUBLISHED)されていないと、来院に紐付けできません。作成中のCRFはDRAFT列としてグレーで表示され、選択自体がブロックされるため、紐付けできない場合はまずCRF管理で発行状態を確認してください。
パス CRFマッピング紐付けの編集

概要

編集を押すと紐付けを変更できます。セルを選択するたびに未マッピング → 必須 → 任意 → 未マッピングの順に切り替わり、変更内容は完了を押して初めて保存されます。複数のセルをまとめて扱う場合は、複数選択を使います。

画面説明

設定 直接操作する位置
結果 すぐ上の設定で変わる位置
参考

完了 — 変更した紐付けを保存します。このボタンを押すまで保存されません。

キャンセル — 変更内容を破棄して照会モードに戻ります。

選択 — 複数選択モードをオンにします。オフのままでも、Shift または Ctrl を押しながら選択すれば同じです。

フォーム順序 — 照会モードと同じです 3.3。

見出しのバッジが紐付けの編集に変わります。今どのモードかを、ここで確認してください。

下の案内 — 「セルをクリック: 未マッピング → 必須 → 任意 → 未マッピングの順に切り替え · 変更は『完了』ボタンで保存」

続く案内 — 「Shift/Ctrl+Click または『選択』ボタンで複数選択 → OPTIONAL 一括」です。複数のセルを一度に任意 (OPTIONAL)へ変更します。

右側の案内がマトリクスでセルを選択してくださいに変わります。

注意事項

必須確認 データ破損 · フォーム完了不可

  • • 必須と任意は意味が違います。必須で紐付けたCRFは、その来院を完了するために必ず入力しなければなりません。任意は空欄のままでも、来院を閉じることができます。切り替えは未マッピングから先に必須へ進むため、任意にするには、もう一度押してください。
パス CRFマッピングCRFフォーム順序

概要

被験者の来院画面でCRFカードがどの順番で表示されるかを決めます。ここで決めた順序は、マトリクスのフォーム列の並べ替えにもそのまま使われるため、記録者が実際に入力する順番に合わせておくと、現場で迷わずに済みます。

画面説明

設定 直接操作する位置
結果 すぐ上の設定で変わる位置
参考

来院 — 順序を決める来院を選びます。括弧内は、その来院に紐付けられたCRFの件数です。

ハンドルをドラッグして順序を変更します。

▲▼で1つずつ上下に移動することもできます。

閉じる — ウィンドウを閉じます。横のフォーム列の並べ替えを解除は、マトリクスの列の並べ替えだけを解除し、順序そのものは残します。

説明 — ここでの順序が被験者の来院画面のカード順であり、同時にマトリクスのフォーム列の順序でもある、という意味です。

一覧の番号とCRFの名前・コードです。右側の数字が、現在の並べ順の値です。

黄色の警告 — 「並び順の値が重なっているフォームが N件」。重なった位置はフォームコード順にずれて表示されるため、表示順が変わることがあります。

同じ警告の解決案内 — 一度並べ替えると、並び順の値が10刻みで振り直されます。

注意事項

誤解しやすい動作

  • • 並び順の値が重なっているのは、構築ファイルから取り込んだ初期値が原因です。重なったままにすると表示順が意図と異なる場合があるため、警告が表示されたら一度ドラッグして並べ替え、間隔を振り直してください。
