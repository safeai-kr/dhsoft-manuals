# 프로젝트 권 영문 번역 메모 (en)

확인이 필요한 곳과 판단한 곳을 적었습니다. 번역 본문에는 표시를 넣지 않았습니다.

## 실제 영문 UI 문구를 알 수 없는 곳
- 상태 이름: 설정 중 = Setup, 테스트 = Test, 운영 중 = Active, 종료 = Closed, 보관 = Archived로 옮겼습니다. 제품 화면의 공식 영문 표기와 맞는지 확인해 주세요. 괄호 안 코드(SETUP, ACTIVE, CLOSED 등)는 그대로 두었습니다.
- 버튼 「실행」은 Run으로 옮겼습니다. 화면에 다른 영문 라벨이 있다면 알려 주세요.
- 「시스템 관리자」(System administrator), 「워크스페이스 관리자」(workspace administrator)는 용어를 새로 정했습니다.
- 메뉴 「참여 기관」은 Sites로 옮겼습니다. 같은 뜻의 「기관」은 소문자 site로 옮겼습니다. 참여기관 권과 용어를 맞췄습니다.

## 판단한 곳
- 「1.2 유의사항 참조」처럼 권 안의 위치를 가리키는 말은 (see Precautions in 1.2)로 풀었습니다.
- 「전자서명 비밀번호」와 「로그인 비밀번호」는 서로 다른 값이라는 뜻을 살려 signature-only password, login password로 구별했습니다.
- 「감사 추적」은 glossary의 audit trail을 그대로 썼습니다.
- 「PI」와 「ACTIVE → CLOSED」 같은 표기는 원문 그대로 두었습니다.

## 원문에서 눈여겨볼 곳
- 3.7 서명 목적 항목 안내에 서명 의미가 「승인자 확인」으로 고정이라고 적혀 있습니다. 영문도 approver review로 옮겼습니다.
- 3.1 전제 조건 안내 「초록 체크는 통과를 뜻하지 않는다」는 원문 취지를 그대로 옮겼습니다.
- 3.2 「부작용」 배너는 임상적 이상반응이 아니라 전이에 따른 화면 영향이라는 설명을 그대로 살렸습니다.
