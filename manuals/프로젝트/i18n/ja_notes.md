# 프로젝트 권 일본어 번역 메모 (hy0909 검토용)

## 판단이 필요한 곳
- **허가일 → 承認日**: 기본 보관 정책 「표준 (허가일 + 3년)」을 承認日로 옮겼습니다. 규제상 許可日가 맞는 경우라면 바꿔야 합니다. 확인이 필요합니다.
- **참여 기관 → 参加施設, 기관 → 施設**: 임상시험 업계에서 쓰는 말로 골랐습니다. 다른 권(참여기관 권)과 같은 단어를 씁니다. 용어집에 아직 없어 새로 넣었습니다.
- **전이 → 移行, 운영 전환 → 運用への切り替え**: 상태가 바뀌는 동작 전체는 「移行」, 운영 시작 버튼 쪽은 「切り替え」로 나눴습니다.
- **상태 코드 SETUP · TESTING · ACTIVE · CLOSED · ARCHIVED · HARD_LOCK**: 원문처럼 영문 그대로 두었습니다. 화면 표시 문구(설정 중 · 테스트 · 운영 중 · 종료 · 보관)만 번역했습니다.
- **확인 창 → 確認ダイアログ, 모달 → モーダル**: 권 안에서 같은 말로 통일했습니다.

## 원문에서 눈에 띈 점 (그대로 번역함)
- 테스트 데이터 삭제 확인 창(3.3 유의사항): 「次のデータが」로 시작하지만 뒤에 목록이 없습니다. 원문 그대로 옮겼습니다.
- 3.1 유의사항: 전제 조건의 초록 체크를 「合格」으로 읽으면 안 된다는 내용입니다. 원문 취지대로 옮겼습니다.
- 「(1.2 유의사항 참조)」처럼 본문 괄호 안에 참조가 들어간 곳은 괄호를 그대로 두었습니다.
