# 기관관리 일본어(ja) 번역 메모

번역 기준: TRANSLATION_BRIEF.md

## 판단이 필요했던 곳

1. 「기관」은 機関으로 옮기고, 「참여 기관」은 参加機関으로 옮겼다. 임상시험 현장에서는 施設이라는 말도 쓰므로, 일본 쪽 관례와 맞는지 확인해 주세요. [확인 필요]
2. 「유형」은 Type 필드의 한국어 설명이라 種別로 옮겼다. 타입 설정 화면의 タイプ와 섞이지 않게 했다.
3. 「활성 상태」는 有効状態로, 「활성 열」은 有効列로 옮겼다. 상태 배지 자체는 「활성 → 有効」 용어집 번역을 따랐다.
4. 「검사」는 기관명을 입력할 때 기존 기관과 대조하는 동작이다. 값 검사를 뜻하는 チェック와 구분해 照合으로 옮겼다. 화면 문구가 확정되면 다시 맞춰 주세요.
5. 「연구책임자」는 研究責任者로, 「감사자」는 監査者로 옮겼다. CRF 볼륨의 PI·AUDITOR 표기 원칙과 충돌하지 않도록 본문에는 Latin 약어를 넣지 않았다.
6. 「참조 중」은 参照中으로 옮겼다. 삭제 불가 안내가 이 말에 기대고 있어, 여러 곳에서 같은 말로 통일했다.
7. 「변경 이력」은 용어집의 変更履歴를 그대로 썼다. 메뉴 항목과 화면 제목 모두 같은 말이다.
8. 「담당자 이메일」·「담당자 전화」처럼 항목 이름 뒤에 괄호로 설명이 붙은 곳은, 원문과 같은 자리에 일본어 설명을 넣었다. 예: Contact Email(担当者メール).
9. 「생성 후 변경 불가」는 (作成後は変更不可)로 옮겼다. 원문의 괄호 표기를 그대로 살렸다.

## 구조 확인

- 원문에 없던 굵은 글씨를 한 번 잘못 넣었다가(검색·국가·유형·활성 상태 항목) 제거했다. 최종 check_tr 결과는 문제 0이다.
- 「&gt;」 같은 엔티티는 쓰지 않았다.
- 참조 번호(1.2, 1.3, 2.1, 2.3, 3.1, 3.2, 3.3)는 원문과 같다.
