# 기관관리 독일어(de) 번역 메모

확인이 필요한 곳과 판단한 곳을 정리했습니다. 번역문 안에는 표시를 넣지 않았습니다.

1. **실제 독일어 UI 문구를 모릅니다.** 버튼과 메뉴(Neue Einrichtung, Registrieren, Adresssuche, Bearbeiten, Deaktivieren, Änderungshistorie), 필드명(Aktivstatus, Typ, Land, Notiz), 인용된 안내문(「(nach Erstellung nicht änderbar)」, 「Diese Warnung verhindert die Registrierung nicht」)은 용어 기준으로 맞춘 번역입니다. 실제 화면 문구와 다르면 알려 주세요.
2. **「연구책임자」는 Hauptprüfer로 옮겼습니다.** 원문에 PI라는 말이 없어 PI는 붙이지 않았습니다. 용어집에도 이 용어가 없어서 새로 정한 번역입니다.
3. **「Type」과 「Country」는 원문대로 영문 라벨을 두고 뒤에 독일어를 붙였습니다.** 원문이 「Type(유형)」 형태라서 그 구조를 따랐습니다. 「Type (Typ)」, 「Country (Land)」 형태입니다.
4. **「활성 상태」 열 이름은 두 가지로 적혀 있습니다.** 원문에서 3.2 절은 「활성 열」이라고, 1.1·1.2 절은 「활성 상태」라고 씁니다. 독일어에서는 Aktivstatus로 통일했습니다. 사용자 화면에 열 이름이 하나로 정해져 있는지 확인해 주세요.
5. **「집계」는 Übersicht로 옮겼습니다.** 목록 맨 위에 나오는 합계 숫자 묶음을 뜻합니다.
6. **「수행자」는 Ausführende Person, 「Action」은 Aktionsart로 옮겼습니다.** 감사 기록의 작업 종류 필터를 가리킵니다.
7. **「중복」은 Dublette로 옮겼습니다.** 「중복 등록」은 같은 기관을 두 번 등록하는 것을 뜻합니다.
8. **「감사 기록」은 Audit-Trail-Eintrag로 옮겼습니다.** 용어집의 「감사 추적 → Audit-Trail」과 맞추기 위해 하이픈 표기를 썼습니다.
9. **사용자관리 매뉴얼과 용어를 맞췄습니다.** 「기관 관리」는 Einrichtungsverwaltung, 「시스템 관리자」는 Systemadministrator, 「워크스페이스 관리자」는 Workspace-Administrator로 같습니다. 「기관」은 모두 Einrichtung으로 옮겼습니다.
10. **Sie(존칭)로 통일했습니다.** 명령형 문장은 「Sie + 동사」 또는 「동사 + Sie」 형태로 쓰고, 명령형 어미는 쓰지 않았습니다.
