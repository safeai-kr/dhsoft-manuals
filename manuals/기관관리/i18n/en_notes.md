# 기관관리 영문 번역 메모 (en)

확인이 필요한 곳과 판단한 곳을 적었습니다. 번역문 안에는 표시를 넣지 않았습니다.

## 실제 UI 문구를 모르는 곳
- 열과 필터 이름 「활성 상태」는 `Active status`로 옮겼습니다. 화면 헤더 문구를 확인해 주세요.
- 「유사 명칭 경고」 안내 문구와 절 제목은 영문 UI 문구가 없어 제가 정했습니다.
- 수정 화면에서 기관 코드 옆에 붙는 「(생성 후 변경 불가)」는 `(Cannot be changed after creation)`입니다.
- 담당자 이메일·전화 라벨 「Contact Email」「Contact Phone」은 원문이 영문 키여서 그대로 두고, 괄호 안에 `Contact person email`, `Contact person phone`을 덧붙였습니다. 화면 문구가 다르면 알려 주세요.

## 판단으로 바꾼 곳
- 「참조」는 문맥에 따라 `referenced`(참조 중인 기관), `references`(참조 수)로 옮겼습니다. 용어집의 「참조=References」는 폼 참조 맥락이라 그대로 쓰지 않았습니다.
- 용어집의 「기관 (정상범위 단위)=site」는 검사 정상범위 맥락입니다. 이 권의 「기관」은 `Institution`으로 옮겼습니다.
- 「메타 정보」는 `basic information`(기본 정보)으로 풀어 옮겼습니다.
- 「연구책임자」는 `Principal investigator`로 풀어 옮겼습니다. 원문에 PI 약어가 없어 줄이지 않았습니다.
- 변경 이력 필터의 「작업 종류」는 `Action`으로 옮겼습니다. 같은 낱말이 열 이름으로도 나옵니다.
- 「수행자」는 `Performed by`, 「메모」는 `Memo`로 옮겼습니다.
- 「전체」 같은 용어집 기존 항목과 겹치는 낱말은 기관관리 용어집에 다시 넣지 않았습니다. 「기본 정보」 역시 기존 번역(Basic information)을 그대로 씁니다.
- 「비활성화」와 「상세 보기」는 사용자관리 권과 같은 번역을 씁니다.
- 「institutionCode」 옆 괄호 설명은 `(Institution code)`로 남겼습니다. 코드명은 번역하지 않았습니다.
