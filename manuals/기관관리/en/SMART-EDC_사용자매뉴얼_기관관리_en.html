Path Platform homeInstitution management

Overview

This screen manages institutions across the entire system. Institutions registered here become the choices when you create participating institutions for each project, so this list is the master shared by all projects.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Open Institution management in the left menu.

New institution — Registers a new institution 2.1. If you do not have registration permission, this button is not shown.

Summary — Shows the total number of institutions, the number of active and inactive institutions, and the number of registered countries.

Search and filters — Narrow down the list 1.2.

The subtitle explains the purpose of this list — participating institutions in projects refer to the institutions registered here.

The table shows institution code · institution name · type · country · active status · created on. Select an institution name to go to its detail screen 3.1.

Precautions

Easily misunderstood behavior

  • • Only system administrators can register or edit institutions. Workspace administrators, principal investigators and auditors can view the list but cannot make changes.
Path Platform homeInstitution management

Overview

As the number of institutions grows, they are hard to find in the list. Narrow the scope with a search term and three conditions before you work.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Search — You can find institutions by institution code, institution name or English name.

Country — Narrows the list to registered countries.

Type — Narrows the list by institution type, such as hospital or university/research institute.

Active status — By default, only active institutions are shown. To check inactive institutions, change this setting.

Institution codes cannot be changed after registration, so searching by code is the most reliable way to find an institution.

Precautions

Easily misunderstood behavior

  • • The default filter shows only active institutions, so inactive institutions are not visible at first. If you cannot find an institution, check this condition first.

Overview

Select the ⋯ at the right end of each row to open the actions for that institution. These are four entry points you can use directly without leaving the list.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

⋯ — Select to open the action menu for that row. It appears on every row regardless of permissions, but the number of items in the menu varies by permission.

Precautions

Easily misunderstood behavior

  • • Not all four items in the menu are always shown. Without registration permission, the Edit and Deactivate items are hidden, and only View details and Change history remain. A shorter menu is not an error.
  • • There is no Delete in this menu. Deletion is possible only from the institution detail screen, and an institution that is currently referenced cannot be deleted 3.1.

Path Institution managementRegister new institution

Overview

Registers a new institution. Items marked with an asterisk must be entered. You can fill in the rest later on the edit screen.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

institutionCode (Institution code) — A unique code that distinguishes the institution. It cannot be changed after registration, so decide carefully.

Institution name — Enter the official name.

Type — Select a hospital, university/research institute, or other type.

Country — Select the country where the institution is located.

Address search — Find and fill in the postal code and address. You can also type them in directly.

Register — Stays disabled until all required items are filled in.

active (Active status) — Active by default. If you turn it off before registering, the institution is inactive from the start.

English name — Optional. If entered, you can also find the institution by its English name in the list.

Contact Email (Contact person email) · Contact Phone (Contact person phone) — Optional fields.

Precautions

Must check Data corruption · Form cannot be completed

  • • Institution codes cannot be changed after registration. If you register one incorrectly, you cannot fix it by editing, and if a participating institution already references it, it cannot be deleted either.
Path Institution managementRegister new institution

Overview

If the same institution is registered twice under different codes, each project refers to a different institution, and the statistics split apart. To prevent this, the screen shows already registered institutions when you enter an institution name.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

When you enter the institution name, a check runs.

Already registered institutions are listed with their codes. If the institution you were looking for is in this list, do not register it again. Use that institution instead.

As the notice says, this warning does not block registration. If you have confirmed that it is not a duplicate, you can proceed as is.

Precautions

Must check Data corruption · Form cannot be completed

  • • If you register the same institution twice, you cannot merge them later. Institution codes cannot be changed, and deletion is blocked once references exist, so check the list first.
Path Institution managementEdit institution

Overview

Edits the basic information of a registered institution. The input items are the same as on the registration screen, but the institution code cannot be changed.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

You can change the institution name, English name, type and country.

You can also fill in or correct the address and contact information here.

Save — Applies your changes.

The notice at the top shows how many participating institutions reference this institution, and also notes that changes are applied to all of them immediately.

The institutionCode field has a gray background and cannot be selected. “(Cannot be changed after creation)” is shown next to the label.

Cancel — Discards your changes and returns to the previous screen.

Precautions

Must check Data corruption · Form cannot be completed

  • • If you change the institution name, it is immediately reflected in the participating institutions of every project that references this institution. If any project is in operation, consult the people concerned before making the change.

Path Institution managementInstitution details

Overview

Shows all information for a single institution, together with the list of participating institutions that reference it. Deletion is possible only on this screen.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Edit — Goes to the basic information edit screen 2.3.

Deactivate — Sets the institution to inactive 3.2.

Delete — Permanently deletes the institution. An institution that is referenced cannot be selected, and a notice that deletion is not possible is shown together with the number of references.

At the top, the institution code, type, country and active status appear as badges, followed below by the official name and English name.

Contact and address — The registered address and contact information. Items not entered are shown as “-”.

Participation statistics — The number of participating institutions and projects that reference this institution. Check the reference count on this screen.

Precautions

Must check Data corruption · Form cannot be completed

  • • An institution that is referenced cannot be deleted. For an institution you no longer use, do not delete it. Deactivate it instead — existing references and records are kept 3.2.
Path Institution managementDeactivation result

Overview

This is how you remove an institution you no longer use from the list. Unlike deletion, the record is kept and existing references are not broken, so use deactivation for institutions that have been in use.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Perform it from the ⋯ menu on the row 1.3. Use the same place to reverse it.

The status badge in the Active status column changes to Inactive, and the whole row is shown dimmed. Check the current status of each institution in this column.

Registration details such as the institution code and name remain as they are. Nothing is deleted; only the status changes.

Precautions

Easily misunderstood behavior

  • • Inactive institutions are not shown in the default list. To find them again, change the active status filter 1.2.
Path Institution managementInstitution change history

Overview

Shows the changes made to institutions. It records who changed what and when, and this record cannot be edited or deleted.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Institution — Select the institution to view.

Action — Narrows the list by type of change, such as register, edit or deactivate.

Performed by — Narrows the list to users who made the change.

Period — The start and end dates to view.

Search — Find by institution code, institution name or memo.

The subtitle explains the nature of these records — this is an audit record that cannot be edited or deleted.

The table shows date-time · institution · action · change details · performed by · memo.

Precautions

Easily misunderstood behavior

  • • The narrower the conditions, the fewer records appear. If you cannot see any records, check the period first. Changes outside the default period are not shown.
