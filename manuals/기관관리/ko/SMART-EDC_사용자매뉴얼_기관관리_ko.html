개요

시스템 전역의 기관을 관리하는 화면입니다. 여기에 등록된 기관이 각 프로젝트의 참여 기관을 만들 때 선택지가 되므로, 이 목록은 모든 프로젝트가 공유하는 마스터입니다.

설정 직접 조작하는 위치
결과 바로 위 설정으로 바뀌는 위치
참고

왼쪽 메뉴의 기관 관리 로 진입합니다.

신규 기관 — 기관을 새로 등록합니다 2.1. 등록 권한이 없으면 이 버튼은 표시되지 않습니다.

집계 — 전체 기관 수와 활성·비활성 수, 등록된 국가 수가 표시됩니다.

검색과 필터 — 목록을 좁힙니다 1.2.

부제에 이 목록의 성격이 안내됩니다 — 프로젝트의 참여 기관은 여기 등록된 기관을 참조합니다.

표에는 기관 코드·기관명·유형·국가·활성 상태·생성일이 표시됩니다. 기관명을 선택하면 상세 화면으로 이동합니다 3.1.

유의사항

오해하기 쉬운 동작

  • • 기관 등록·수정은 시스템 관리자만 할 수 있습니다. 워크스페이스 관리자 · 연구책임자 · 감사자는 목록을 조회할 수 있으나 변경할 수 없습니다.

국가 — 등록된 국가로 좁힙니다.

유형 — 병원·대학/연구소 등 기관 유형으로 좁힙니다.

활성 상태 — 기본값은 활성 기관만 보여줍니다. 비활성 기관을 확인하려면 여기를 바꾸십시오.

기관 코드는 등록 후 변경할 수 없으므로, 코드로 찾는 것이 가장 확실합니다.

상세 보기 — 기관 상세로 이동합니다 3.1. 기관명을 직접 선택해도 같은 화면으로 갑니다.

경로 기관 관리신규 기관 등록

개요

기관을 새로 등록합니다. 별표가 붙은 항목은 반드시 입력해야 하며, 나머지는 나중에 수정 화면에서 채울 수 있습니다.

화면 설명

설정 직접 조작하는 위치
결과 바로 위 설정으로 바뀌는 위치
참고

institutionCode(기관 코드) — 기관을 구분하는 고유 코드입니다. 등록 후에는 변경할 수 없으므로 신중하게 정하십시오.

기관명 — 정식 명칭을 입력합니다.

Type(유형) — 병원·대학/연구소 등에서 선택합니다.

Country(국가) — 기관이 속한 국가를 선택합니다.

주소 검색 — 우편번호와 주소를 찾아 채웁니다. 직접 입력할 수도 있습니다.

등록 — 필수 항목이 모두 채워질 때까지 비활성 상태로 유지됩니다.

active(활성 상태) — 기본값은 활성입니다. 해제하고 등록하면 처음부터 비활성 기관이 됩니다.

영문 명칭 — 선택 항목이지만, 입력하면 목록에서 영문으로도 찾을 수 있습니다.

Contact Email(담당자 이메일) · Contact Phone(담당자 전화) — 선택 항목입니다.

유의사항

필수 확인 데이터 손상 · 폼 완료 불가

  • • 기관 코드는 등록 후 변경할 수 없습니다. 잘못 등록하면 수정으로 고칠 수 없고, 이미 참여 기관에서 참조 중이면 삭제도 되지 않습니다.
경로 기관 관리신규 기관 등록

개요

같은 기관이 다른 코드로 두 번 등록되면 프로젝트마다 다른 기관을 참조하게 되어 통계가 갈라집니다. 그것을 막기 위해 기관명을 입력할 때 이미 등록된 기관을 함께 보여줍니다.

화면 설명

설정 직접 조작하는 위치
결과 바로 위 설정으로 바뀌는 위치
참고

기관명 을 입력하면 검사가 수행됩니다.

이미 등록된 기관이 코드와 함께 나열됩니다. 찾으려던 기관이 이 안에 있으면 새로 등록하지 말고 그 기관을 사용하십시오.

안내 문구대로 이 경고는 등록을 막지 않습니다. 중복이 아님을 확인했다면 그대로 진행할 수 있습니다.

유의사항

필수 확인 데이터 손상 · 폼 완료 불가

  • • 같은 기관을 중복 등록하면 나중에 합칠 수 없습니다. 기관 코드는 변경할 수 없고 참조가 생긴 뒤에는 삭제도 막히므로, 목록을 먼저 확인하십시오.
경로 기관 관리기관 수정

개요

등록된 기관의 메타 정보를 수정합니다. 입력 항목은 등록 화면과 같지만 기관 코드만 바꿀 수 없습니다.

화면 설명

설정 직접 조작하는 위치
결과 바로 위 설정으로 바뀌는 위치
참고

기관명·영문 명칭·유형·국가를 변경할 수 있습니다.

주소와 연락처도 여기에서 채우거나 고칩니다.

저장 — 변경한 내용을 반영합니다.

상단 안내에 이 기관을 참조 중인 참여 기관 수가 표시되고, 변경이 즉시 전부에 반영된다는 점이 함께 안내됩니다.

institutionCode 입력란은 바탕이 회색이고 선택할 수 없습니다. 라벨 옆에 “(생성 후 변경 불가)” 가 표시됩니다.

취소 — 변경을 버리고 돌아갑니다.

유의사항

필수 확인 데이터 손상 · 폼 완료 불가

  • • 기관명을 바꾸면 이 기관을 참조하는 모든 프로젝트의 참여 기관에 즉시 반영됩니다. 운영 중인 프로젝트가 있다면 변경 전에 관련 담당자와 협의하십시오.

개요

단일 기관의 전체 정보와 이 기관을 참조 중인 참여 기관 목록을 함께 보여줍니다. 삭제는 이 화면에서만 할 수 있습니다.

화면 설명

설정 직접 조작하는 위치
결과 바로 위 설정으로 바뀌는 위치
참고

수정 — 메타 정보 수정 화면으로 이동합니다 2.3.

비활성화 — 기관을 비활성 상태로 바꿉니다 3.2.

삭제 — 기관을 영구 삭제합니다. 참조 중인 기관은 선택할 수 없고 참조 수와 함께 삭제 불가가 안내됩니다.

머리에 기관 코드·유형·국가·활성 상태가 배지로 표시되고 그 아래 정식 명칭과 영문 명칭이 이어집니다.

연락·주소 — 등록된 주소와 연락처입니다. 입력하지 않은 항목은 “-” 로 표시됩니다.

참여 통계 — 이 기관을 참조하는 참여 기관 수와 프로젝트 수입니다. 참조 수는 이 화면에서 확인하십시오.

유의사항

필수 확인 데이터 손상 · 폼 완료 불가

  • • 참조 중인 기관은 삭제할 수 없습니다. 더 쓰지 않는 기관은 삭제하지 말고 비활성화하십시오 — 기존 참조와 기록이 보존됩니다 3.2.

개요

더 쓰지 않는 기관을 목록에서 걷어내는 방법입니다. 삭제와 달리 기록이 남고 기존 참조도 끊기지 않으므로, 운영 중이던 기관에는 비활성화를 사용합니다.

개요

기관에 가해진 변경을 조회합니다. 누가 언제 무엇을 바꾸었는지가 남으며, 이 기록은 수정하거나 삭제할 수 없습니다.
