Path Profile menuMy profile

Overview

This screen lets you view and manage your own account. Open it from View profile in the profile menu at the top right. All account-related settings branch out from this screen, which is divided into four areas.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Concurrent session block notice — A record that your session was ended by a login from another device 1.2. If there is no such record, it is not shown.

Basic information — Your name and email. Only your name can be changed 1.3.

My activity management — Five entry points that lead to Password · E-signature password · Pending signatures · Notification settings · Session history 1.4.

Recent login history — Recent access records for your account 1.5.

Precautions

Easily misunderstood behavior

  • • This screen is for your own account only. You cannot view or change other users' information. That function is on the User management screen of the system administrator.
Path Profile menuMy profile

Overview

Only one simultaneous session is allowed per account. If you log in with the same account on another device or browser, the session that was already open ends, and the record is added to this banner. If you did not make this login yourself, your account may have been used without your permission, so you must check it immediately.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

View full history — Check all records, including the ones that are omitted 3.3.

Close — Closing the banner marks all displayed records as checked. This cannot be undone, so close the banner only after you have reviewed its contents.

The banner shows only the 5 most recent records, and the number of remaining records is indicated below as a number. Each line shows the time of occurrence and the information about the device used to log in.

Precautions

Must check Data corruption · Form cannot be completed

  • • If there is an access record you do not remember, change your password immediately and notify your system administrator 2.1.

Screen guide

Setting Where you operate

Path My profileChange password

Overview

Changes your login password. Use this screen when you know your current password. If you have forgotten your password, use the reset option on the login screen.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Current password — Enter the password you are using now.

New password — Enter the password you want to use.

The condition list updates as you type. Each condition you meet changes to a check mark.

Confirm password — Enter the same value once more.

Change — Stays disabled until all three fields are correct.

Password visibility toggle — Shows the entered value in plain text. It is available in all three fields.

Cancel — Stops the change and returns you to the previous screen.

Precautions

Easily misunderstood behavior

  • • The specific conditions and how many there are may vary depending on system settings. Use the list shown on the screen as your reference.
Path My profileChange e-signature password

Overview

Changes the password used for e-signatures. It is a separate value from your login password. When you sign, you are authenticated once more with your user account and this password. Only you can set it, and no separate permission is required.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Current e-signature password — Enter the e-signature password you are using now.

New e-signature password — Enter the value you want to use. The complexity rules are the same as for the login password.

Confirm password — Enter the same value once more.

The complexity check list updates as you type.

Save — Stays disabled until all items are met.

The notice at the top explains what this password is for — it must be different from your login password, and it is used for two-factor authentication when you sign.

The last item in the list (must differ from the login password) is checked by the system when you save. Whether it is met is not updated while you type.

Precautions

Must check Data corruption · Form cannot be completed

  • • E-signing is an activity regulated under 21 CFR Part 11. Do not share your signature password with anyone else. A signature is recorded as performed by you and cannot be canceled.

Path My profileNotification settings

Overview

Manage which notifications you receive, by type. You can turn in-app notifications and email notifications on and off separately.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Enable notifications — The master switch. If you turn it off, all notifications are blocked regardless of the settings below.

In-app — Notifications you receive inside the system screen.

Email — Notifications you receive at your registered email address.

Save — Applies the settings you changed. If you have not changed anything, it is disabled.

The count shown in the title is the number of types you can receive with your permissions, shown together with the total number of types. Notifications you have no permission for do not appear in the list.

The gray text in each row is a code that identifies the notification type. Giving this code when you contact support speeds up the check.

Precautions

Must check Data corruption · Form cannot be completed

  • • If you turn off Enable notifications, important notifications such as account lock or invalid signature are also blocked. We recommend turning off notifications by type instead.
Path My profilePending signatures

Overview

This is the list of items you need to sign. Other people's signing items are not shown, and everyone can check their own list without any separate permission.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Signing timing — Narrows the list by the point at which a signature is required.

Period (from) — Start date of the search.

Period (to) — End date of the search.

Search — Searches by signing target or requester.

Refresh — Reloads the list.

The three boxes at the top show the total number of pending items, the number of overdue items, and the number of items on time, respectively.

The notice box tells you that the signature for the current form is excluded from the requirements, so the signing button is disabled. When the scope is widened, it works again.

If there are no pending items, an empty list is shown, along with guidance on when items appear.

Precautions

Easily misunderstood behavior

  • • Signatures made after the deadline are counted as late signatures and remain in the audit trail. Check the summary boxes at the top first.
Path My profileSession replacement history

Overview

This is the full record of sessions ended by a login from another device. The banner on the profile screen shows only the 5 most recent records, so use this screen to check all of them.

Screen guide

Setting Where you operate
Result What the setting above changes
Note

Check status — Shows checked records and unchecked records separately.

Refresh — Reloads the list.

My profile — Returns to the profile screen.

The table has three columns: time of occurrence · access address · access device.

The Check column shows a separate mark on each record that has not been checked yet.

Precautions

Easily misunderstood behavior

  • • You cannot mark records as checked on this screen. They are marked only when you close the notification banner on the profile screen, and at that time all records shown in the banner are marked as checked together 1.2.
