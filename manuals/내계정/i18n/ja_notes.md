# 내계정 권 일본어 번역 메모 (ja)

## 실제 화면 문구를 확인해야 할 곳
- 토글 라벨 「通知受信を有効にする」(원문 「알림 수신 사용」): 전체 스위치 라벨이라 실제 일본어 화면 문구와 맞는지 확인 필요. 본문 주의 문구에서도 같은 말을 쓴다.
- 카드 버튼 「パスワード · 変更」「電子署名パスワード · 変更」「マイ署名待ち · 移動」「通知設定 · 設定」「セッション置換履歴 · 表示」: 원문 구조(항목 · 동작)를 그대로 살렸다. 실제 버튼 문구가 다르면 바꿔야 한다.
- 표 머리 「発生時刻」「接続アドレス」「接続端末」, 상태 「確認状態」: 화면 표기 확인 필요.

## 판단이 들어간 곳
- 4번 항목(p4s3i0)의 참조 「2.1」: 원문에서 「2.1」이 「시스템 관리자에게 알리십시오」 앞에 붙어 있어 위치를 그대로 두었다. 2.1 비밀번호 변경을 가리키는지, 시스템 관리자 안내를 가리키는지 원문만으로는 불분명하다. 원문 의도를 확인해 달라.
- 「1.2」를 가리키는 본문 문장(p7s3i0)은 원문에 참조 span이 없어 span 없이 두었다.
- 장 제목 「通知 · 署名 · セッション」은 다른 목록 구분과 같은 「 · 」를 썼다.
- 「セッション置換履歴」은 h2 제목과 카드 버튼에서 같게 썼다. 표지 부제만 「セッション履歴」로 줄였다.
- 「本人」는 원문 「본인」을 그대로 옮긴 말이다.
- 「21 CFR Part 11」은 원문 그대로 두었다.
- 「期間 (from)」「期間 (to)」는 원문의 영문 표기를 그대로 두었다.
- 「新規パスワード」는 로그인 권과 맞췄다.
