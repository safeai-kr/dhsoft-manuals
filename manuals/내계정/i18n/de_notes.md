# 내 계정 권 독일어 번역 메모

- 「접속 주소」는 IP 주소인지 단순한 접속 위치인지 원문만으로는 알 수 없다. Zugriffsadresse로 옮겼다. 실제 값이 IP 주소라면 IP-Adresse로 바꾸는 편이 분명하다.
- 「확인 처리」는 배너를 닫으면 표시된 기록이 한꺼번에 확인된 것으로 바뀌는 동작이다. 독일어로는 als bestätigt markieren으로 옮겼다. 「확인 상태」는 Bestätigungsstatus, 표 열 「확인」은 Bestätigt로 옮겼다.
- 「세션 대체 이력」은 다른 기기에서 로그인해 세션이 끊긴 기록이다. 직역하면 뜻이 흐려져서 Verlauf ersetzter Sitzungen으로 풀어 옮겼다.
- 「서명 대기」와 「지연 서명」은 ausstehende Signatur와 verspätete Signatur로 옮겼다. 지연 서명은 감사 추적에 남는다는 점을 살려 Audit-Trail을 그대로 쓰는 것으로 정리했다.
- 「이중 인증」은 zweistufige Authentifizierung으로 옮겼다. 서명할 때 계정 인증과 서명 비밀번호로 한 번 더 확인하는 방식이라는 뜻을 살렸다.
- 「알림 수신 사용」은 Benachrichtigungsempfang으로 옮겼다. 원문의 바로 뒤 설명과 맞추기 위해 같은 말을 두 곳에 썼다.
- 내 활동 관리 카드의 버튼은 「비밀번호 · 변경」처럼 가운뎃점 구조를 그대로 두고 뒤쪽 말만 옮겼다. 실제 카드 문구는 다를 수 있다.
- 「21 CFR Part 11」은 원문 그대로 두었다.
- 「1.2」처럼 span 밖에 적힌 번호는 숫자 그대로 두었다.
- 캡처 이미지 안의 한국어 글자는 번역하지 않았다.
- doc.title은 빌드 과정에서 쓰이지 않는다. 독일어 HTML 제목은 fixed.json의 문구와 cover.title로 만들어진다.
