# Query 영문 번역 메모 (en)

화면 실제 영문 문구를 알 수 없어 정한 표현과 판단한 곳입니다. 실제 UI 문구와 다르면 알려 주세요.

## 판단한 곳

- **미처리 → Unanswered.** 원문에 OPEN이라는 영문 값이 따로 있어 Open을 쓰면 두 값이 같은 뜻이 됩니다. 그래서 상태 이름은 Unanswered로 했습니다.
- **재질의 → Reopened(상태) / Reopen(동작).** 상태 표는 Reopened, 버튼과 메뉴는 Reopen으로 나눴습니다. 섹션 제목 「재질의(Reopen)」은 Reopen (re-query)로 했습니다.
- **종료 / 종결.** 원문에서 두 말이 섞여 있습니다. 상태는 Closed, 동작은 Close Query, 창 닫기는 Close로 나눴습니다. 「종결 대기」는 Waiting to close로 옮겼습니다.
- **확인 요청(Query).** query request (Query)로 옮겼습니다. Query 자체는 원문대로 Latin으로 둡니다.
- **지연 Query → Overdue Query.** 30일 넘게 답변 없는 건이라는 뜻을 살리려고 고른 말입니다.
- **생성 경로 → Creation source.** 필터와 열의 실제 영문 이름을 알 수 없습니다.
- **표시 중 → Showing.** 필터 적용 후 화면에 보이는 건수라는 뜻으로 골랐습니다.
- **Query 열림 → Query open.** 품질 상태 값 이름으로 쓴 표현입니다. 실제 화면 문구와 맞는지 확인이 필요합니다.
- **Screening No, ⋯, (reopen #1), 1.1 · 1.2 같은 참조는 원문 그대로 둡니다.**
- **담당 → Assignee, 등록자 → creator.** 원문 뜻대로 옮겼습니다.
- **감사자 → auditor, 데이터 관리자 → data manager, 연구책임자 → principal investigator, 모니터요원 → monitor.** 역할 이름은 원문 뜻대로 옮겼습니다. 「모니터요원」은 CRA 약어를 쓰지 않았습니다.

## 실제 화면 문구 확인이 필요한 곳

- 버튼 「답변 저장」「답변 + 값 저장」「종료 실행」「재질의 실행」 영문 라벨
- 「필터 초기화」 「이력·상세 보기」 「표시 중」 영문 라벨
- 「Overdue Query」「Creation source」 의 영문 라벨
