# Query 분권 일본어 번역 메모 (hy0909 검토용)

- **취소 두 가지 번역**: 원문 `취소`가 버튼(입력 취소)과 상태 이름(취소된 Query)으로 함께 쓰입니다. 버튼은 「キャンセル」, 상태 표에서는 「取消」로 나눴습니다. 용어집에는 버튼 기준으로 「キャンセル」만 올렸습니다. 상태를 「キャンセル」로 통일해도 됩니다.
- **질의 · 재질의**: 「질의」는 「照会」, 「재질의」는 「再照会」로 옮겼습니다. Query 자체는 영문 그대로 둡니다. 실제 제품 화면의 일본어 용어를 확인하지 못했으므로 제품 표기와 다르면 알려 주세요.
- **종료 · 종결**: 원문에 「종료」(상태·메뉴)와 「종결」(데이터 입력 화면 버튼)이 따로 있어 「終了」와 「終結」로 구분했습니다. 실제 화면에서 두 말을 같은 뜻으로 쓴다면 하나로 맞추면 됩니다.
- **역할 이름**: 「모니터요원」은 용어집의 「臨床開発モニター」를 따랐습니다. 「연구책임자」는 「研究責任者」로 옮겼고, 용어집에 같은 뜻의 말이 없어 새로 올렸습니다. 「데이터 관리자」(データ管理者), 「감사자」(監査者)도 같은 방식입니다.
- **Query 열림**: 생성 직후 품질 상태 이름을 「Queryオープン」으로 직역했습니다. 제품에 정해진 일본어 상태명이 있는지 확인이 필요합니다.
- **방문**: 용어집의 「방문일=来院日」에 맞춰 「来院」으로 옮겼습니다. 원문의 「Visit」은 영문으로 남겼습니다.
- **괄호 표기**: 일본어 문장 안의 괄호는 전각（ ）로 통일했고, 「(reopen #1)」처럼 영문만 있는 표기는 반각 그대로 두었습니다.
- **화면 용어 미확인**: 「行アクションメニュー」, 「フィルター初期化」, 「終了実行」, 「Reopen実行」 같은 버튼 이름은 실제 일본어 화면 문구가 아니라 원문 뜻을 살린 번역입니다. 실제 화면과 다르면 용어집과 함께 고쳐야 합니다.
- **그 밖의 판단**: 「解消方法」의 「値の訂正」「現行維持」는 원문 설명대로 값 변경 여부에 따라 자동으로 정해지는 결과로 옮겼습니다. 「終了は「終わり」ではなく」처럼 「 」 안의 따옴표 표기를 그대로 살렸습니다.
