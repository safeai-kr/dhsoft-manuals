# SAE 통보 · 권한 관리 권 독일어 번역 메모 (hy0909 확인용)

## 판단이 들어간 곳
- **연구책임자 → Hauptprüfer**: 본문에서는 이 말로 통일했다. 기존 용어집에는 없어서 새로 정했다. 다른 권에서 `Prüfarzt`나 `PI`를 쓰고 있으면 맞춰야 한다. 코드 PI, CRC, CRA, DM, AUDITOR는 그대로 두었다.
- **연구자 → Prüfer**: 「Site를 지정하면 그 기관의 연구자로 등록된다」는 뜻으로 옮겼다.
- **데이터 관리자 → Datenmanager**: 역할 이름 DM은 그대로 두고, 본문 설명만 이 말로 옮겼다.
- **감사자 → Auditor**: 역할 코드 AUDITOR와 맞추려고 영어 그대로 썼다.
- **중대성 전이 → Wechsel der Schwere**, **발화 사유 → Auslöser**: 원문이 뜻을 풀어 써 주지 않는 말이라 짧은 독일어로 옮겼다. 화면에 다른 말이 있으면 알려 달라.
- **Site 제한 → Site-Beschränkung**, **전체 접근 → Vollzugriff**: 「Site」는 제품 용어라 영어 그대로 두었다. 「기관」은 용어집의 Einrichtung을 따랐다.
- **이력 → Historie**, **변경 이력 → Änderungshistorie**: 용어집의 「변경 이력 → Änderungshistorie」를 따랐다. 버튼 「이력」은 짧게 Historie로 했다.
- **배정 → Zuweisung**: 「배정하기」는 Zuweisen으로 했다. 실제 화면 문구는 확인이 필요하다.
- **건너뛰기 → Überspringen**, **덮어쓰기 → Überschreiben**: 가져오기 창의 두 선택지다. 기존 권에 같은 말이 있는지 확인하지 못했다.
- **예약 → Vorbehalten**: 잠긴 칸의 「예약 (PI,CRC)」 표시 문구를 이렇게 옮겼다. 실제 화면에 어떤 독일어 말이 나오는지는 확인하지 못했다.
- **읽기 전용 배지 → Schreibgeschützt**: 용어집의 「읽기 전용」 번역을 그대로 썼다. 배지라면 Nur lesen이 더 자연스러울 수도 있다.
- **캡처 → Aufnahme**: 용어집을 따랐다. 본문에 「(캡처는 …)」이 여러 번 나오는데, 모두 「Aufnahme」로 옮겼다.

## 원문에서 확인이 필요한 곳
- 「p3s4i0」 안내 문장에 「순서는 수신자 추가 → 저장 → 체크 → 저장 이 아니라」라는 말이 있다. 독일어로는 같은 순서를 그대로 옮겼다.
- 「p10s3i0」의 「그 기관의연구자로도」는 원문에 띄어쓰기가 빠진 것 같다. 번역에는 띄어쓰기를 맞춰 옮겼다.
- 「p5s3i0」과 「p13s3i0」에서 연구책임자와 데이터 관리자는 열람 권한 없이 화면이 열리는 것처럼 보인다. 원문대로 옮겼으니 실제 화면 동작과 맞는지 한번 봐 주면 좋겠다.
- 「p9s2i9」에서 워크스페이스 멤버만 배정할 수 있다고 한다. 「p9s3i0」의 설명과 같은 내용이다. 두 곳의 말투만 맞췄다.

## 화면 문구로 확인하지 못한 것
- 버튼, 탭, 선택지 문구는 모두 독일어 화면에 있는지 확인하지 못했다. 용어집에 없던 것은 새로 정해 `i18n/glossary_de.json`에 넣었다.
- 「AE 지정」 화면 이름은 Festlegung으로 옮겼다. 다른 권의 화면 이름과 맞는지 확인이 필요하다.
