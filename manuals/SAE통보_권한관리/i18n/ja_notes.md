# SAE 통보 · 권한 관리 일본어 번역 메모 (hy0909 검토용)

번역 파일: `data/ja.json` (195개 단위) · 용어집: `i18n/glossary_ja.json` (146개)

## 확인이 필요한 곳

1. **「기관」 → 施設.** Site를 가리키는 말이라 施設로 옮겼다. Site는 영문 그대로 두었다. 「담당 기관」은 担当施設.
2. **「과제」 → 試験.** 2.4 설명("여러 과제에 반복해 쓸 때")과 1.2 유의사항("과제가 열람을 승인한 범위"), 두 곳. 화면 용어 Project(プロジェクト)와 구분하려고 試験을 골랐다. 일본 현장 용어가 다르면 바꿔 주세요.
3. **「연구책임자」·「데이터 관리자」.** 원문에 PI·DM 대신 한국어 명칭이 쓰여 있어 研究責任者·データ管理者로 옮겼다. 일본 임상 용어로는 治験責任医師 쪽이 흔하다.
4. **「인지일」 → 認知日.** 이상사례를 안 날짜를 뜻한다. 일본 쪽 정식 용어가 따로 있으면 알려 주세요.
5. **화면 안의 메시지 문구.** 「발송된 통보가 없습니다.」, 「미리보기 이후 대상 역할이 변경됐습니다…」, 「예약 권한 변경 확인」 등은 원문을 근거로 옮긴 것이다. 실제 일본어 UI 문구는 없으므로 개발 쪽 확인이 필요하다.
6. **색 이름 안내.** 「노란 안내」·「회색 안내」·「파랑 안내」는 각각 黄色の案内·灰色の案内·青の案内로 옮겼다. 실제 색과 다르면 알려 주세요.
7. **원문 오타 보정.** 「기관의연구자로도」처럼 띄어쓰기가 빠진 곳은 일본어에서 자연스럽게 읽히도록 옮겼다. 내용은 바뀌지 않았다.
8. **「창」 → ダイアログ.** 팝업 창 전부를 ダイアログ로 통일했다.
9. **「ICH-GCP §4 Investigator Responsibilities」.** 원문이 이미 영문이라 그대로 두었다.
10. **「역할」 → ロール.** 기존 CRF 용어집의 「역할 (사용자 역할)=ロール」에 맞췄다.

## 판단으로 정한 것

- 원문 「~여부」는 有無로 통일했다 (例: SAE 여부 → SAE有無).
- 「발화」는 발사 뜻이 아니라 통보가 나가는 계기라서 「送信のきっかけ」로 옮겼다.
- 「중대성 전이」는 SAE 여부가 바뀌는 일을 말하므로 「重篤性の移行」.
- 章 제목 「역할 목록·관리」는 ロール一覧・管理.
- 번역문 안에 확인 표시나 한국어 병기는 넣지 않았다.
