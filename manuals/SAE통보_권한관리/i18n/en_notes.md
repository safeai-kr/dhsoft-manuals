# SAE 통보 · 권한 관리 영문 번역 메모 (en)

화면에 실제로 찍힌 영문 문구를 알 수 없어서 정한 표현과 판단한 곳을 적습니다. 실제 UI 영문 라벨과 다르면 알려 주세요.

## 판단한 곳

- **「SAE 여부」 → SAE status.** 필드 이름을 알 수 없습니다. 화면에 영문 라벨이 있다면 그 말로 바꿔야 합니다.
- **「배정」 두 가지 뜻.** 버튼으로 쓰인 「배정」은 Assign, 역할 목록 열과 배정 목록 열의 「배정」은 Assignments(명사)로 나눴습니다. 같은 낱말을 두 번역으로 나눈 셈이라 용어집에는 「배정하기」→Assign만 넣었습니다. 열 이름이 배정 인원인지 배정 날짜인지 원문만으로는 명확하지 않습니다.
- **「기본」 → Default.** 용어집에 「기본」은 탭 이름 Basic으로 이미 있어서, 이 권에서는 역할 종류를 가리키는 말로만 Default를 썼습니다. 용어집에는 넣지 않았습니다.
- **「Site 제한」 → Site-restricted, 「전체 접근」 → Full access.** 화면 문구를 알 수 없어서 붙인 말입니다. 「SITE 제한」 열 이름은 SITE restriction으로 옮겼습니다.
- **「예약」 자물쇠 표시 → Reserved.** 자물쇠 옆 글자를 그대로 옮겼습니다.
- **「이력」 버튼 → History, 「세트 내보내기」 → Export set.** 세트는 set으로 두고, 권한 셋은 permission set, 역할 세트는 role set으로 옮겼습니다.
- **「인지일」 → awareness date.** 메일 본문에 들어가는 날짜라는 것만 알 수 있습니다. 정확한 정의는 확인이 필요합니다.
- **「식별자」 → identifier.** 본문에 실리는 항목 이름으로 옮겼습니다.
- **「중대성 전이」 → seriousness change.** 「아니오 → 예」 화살표는 그대로 두었습니다.
- **「발생 · 보고 구분」, 「첨부 · 완료」 → 열 이름.** 화면 열 이름을 확인할 수 없어서 원문 순서대로 옮긴 임시 이름입니다.
- **인용문 안의 인용.** 원문의 바깥 인용은 “ ”, 안쪽 인용(「SAE 여부」 등)은 ‘ ’로 나눴습니다. 「」는 원칙대로 “ ”로 옮겼습니다.
- **「연구책임자」 → principal investigator, 「모니터요원」 → monitor.** 원문에 약어 PI는 코드 값으로만 나옵니다. 본문에서는 풀어 썼습니다.
- **「관리자」 예시 값 → Admin, 「CTM 읽기」 예시 값 → CTM Read-only.** 캡처에 있는 예시 값이라 실제 화면 값과 다를 수 있습니다.
- **「기관」 → site, 「Site」 → Site.** 「Site」는 제품 용어라 그대로 두었고, 본문의 「기관」은 site로 옮겼습니다.
- **색 이름(노란·회색·파랑 안내).** 원문 색을 그대로 설명하도록 옮겼습니다. 색 이름은 영문 매뉴얼에서도 그대로 쓰는 것이 맞는지 확인이 필요합니다.
- **4.1 참조가 본문에 그냥 적힌 곳.** 원문에서 span이 없는 「4.1」은 그대로 평문으로 두었습니다. 원문과 태그 수를 맞추기 위해서입니다.
- **ICH-GCP §4 Investigator Responsibilities, 21 CFR Part 11 § 11.10(e)** 는 원문 그대로 두었습니다.
