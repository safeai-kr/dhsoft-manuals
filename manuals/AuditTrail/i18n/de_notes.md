# AuditTrail 독일어 번역 메모 (hy0909 확인용)

- **PI·CRA 등 역할명**: 「연구책임자」는 `Hauptprüfer`로 풀었다(원문에 PI 표기가 없어서). 「임상연구모니터요원(CRA)」은 `klinische Monitore (CRA)`로 옮겼다. 독일어 현장 용어가 다르면 알려 주면 바꾼다.
- **「전체」**: 기존 용어집에서 「전체」는 `Voll`(화면 폭 뜻)이다. 카테고리 칩의 「전체」는 필터의 '모두'이므로 `Alle`로 옮겼다. 용어집 항목은 추가하지 않았다.
- **「운영 이력」**: `Betriebshistorie`로 옮겼다. 화면 이름이 확정되면 같은 말로 맞춘다.
- **「통합 조회 / 통합 보기」**: 캡션·부제에서는 `Gesamtansicht`로 통일했다.
- **「추출」**: 기존 용어집의 `Export / Exportdaten`을 따랐다. 「추출 화면」은 `Export-Bildschirm`.
- **「보기」「자세히」「검색」**: 원문의 「」를 독일어 „“로 바꿨다. 「검색」은 자동 조회 설명에서만 나오므로 화면 버튼이 아닌 인용으로 처리했다.
- **카테고리 이름 9종**: 피험자 상태(Probandenstatus), 방문 이벤트(Besuchsereignis), 필드 값 변경(Feldwertänderung), 역할 변경(Rollenänderung), 전자서명(elektronische Signatur), 무작위배정(Randomisierung)은 용어집에 새로 넣었다. SDV·Query·Lock은 원문 그대로 둔다.
- **원문의 「(없음)」**: 변경 전·후 값이 없을 때 쓰는 표시이므로 `(Keine)`로 옮겼다.
- **「-」「—」「#######」「~ 현재」**: 화면에 찍힌 기호라 그대로 두고, 뒤의 설명만 옮겼다.
- **규정 원문 항목**: 원문 안내문의 ICH E6(R3) 장 번호(§5.5.3)와 열린 문서 장(「3. SPONSOR」)이 다르다는 내용은 원문대로 옮겼다. 독일어 문서에서 같은 장 번호를 쓰는지는 확인하지 않았다.
- **`append-only`**: 원문 Latin을 그대로 두었다. 독일어 화면에서 같은 표기가 쓰이는지 확인이 필요하다.
