# 데이터내보내기 영문본 메모 (hy0909 검토용)

## 확인이 필요한 곳
- **「회차」**: 입력 기록 순번이라는 뜻으로 "occurrence number"로 옮겼다. 실제 파일의 열 이름이나 영문 UI 표기와 다를 수 있다.
- **「모니터요원」**: "monitoring staff"로 옮겼다. 앞 권의 CRA(임상연구모니터요원)와 같은 사람인지, 다른 역할인지 원문만으로는 알 수 없다. 같은 사람이라면 "clinical research associate (CRA)"로 맞춰야 한다.
- **메뉴·버튼 영문명**: 「이력 전체 보기」, 「추출 화면 보기」, 「추출 완료와 내려받기」, 「내보내기 허브」(영문은 "Export hub")는 실제 영문 UI 명칭이 아니라 뜻을 살린 임시 번역이다.
- **「추출 경고」 문장**: 서버가 만드는 실제 경고 문장은 원문에 없어서, 원문 설명에 나온 예시 세 가지만 옮겼다.
- **Excel 안내 문구**: "Data may be lost" 같은 문구는 한글 Excel 안내의 뜻을 옮긴 것이다. 영문 Excel 실제 문구와 다를 수 있다.

## 용어 판단
- **「추출」과 「내보내기」**: 앞 권(AuditTrail)과 같은 방식으로 나눴다. 메뉴 이름 「데이터 내보내기」는 "Data export", 작업과 결과 파일을 가리키는 「추출」은 "export"다. 「추출 시작」 버튼은 "Start export"로 옮겼다.
- **「전체」**: 용어집에는 "Full"로 정해져 있다. 이 권에서는 유형·범위의 「전체」 뜻이라 "All"로 옮겼다. 앞 권과 같은 충돌이므로 용어집 정리가 필요하다.
- **「자기 Site」와 「전체 Site」**: 원문 표기를 살려 "Own Site"와 "All Sites"로 옮겼다. 영문 UI에서 다른 이름을 쓴다면 바꿔야 한다.
- **「순위」**: 표 머리글은 "Priority", 본문의 「1순위·2순위」는 "priority 1·2"로 옮겼다.
- **「Lock」 2단계**: 피험자 잠금과 프로젝트 잠금은 "Subject Lock · Project Lock"으로 옮겼다. 원문 표기를 그대로 따랐다.
- **「확정 데이터 Export」·「테스트 데이터 Export」**: 배너 문구의 따옴표 안 원문은 뜻대로 옮기고 Export는 원문대로 살렸다.

## 원문 그대로 둔 것
- 제품 용어 Query, Lock, SDV, Site, Subject, Terminal, DataForm, Visit, DataInstance, DataLock, Export, 화면 코드(SCR-EXP-001 등), 작업 번호 형식(ext_), 샘플 값(020A, S-ONCO-000001 대신 Site 1개(020A))과 옵션 코드(COLUMN_UNION, PER_VERSION, HARD_LOCK, OPEN, ANSWERED, CLOSED)는 그대로 두었다.
- 「3.1」 같은 참조 번호는 원문처럼 `<span class="ref">` 없이 평문으로 두었다. 원문에 span이 없어서 태그를 추가하지 않았다.

## 원문 자체에 있던 것
- 원문은 「이 화면은 데이터 관리자와 감사자만 들어올 수 있습니다」라고 하면서 같은 문단에서 「프로젝트가 종료된 뒤에도 추출은 가능」이라고 적는다. 뜻은 그대로 옮겼다.
- 「1순위 4종·2순위 2종」처럼 유형 수를 세는 문장도 그대로 옮겼다.
- 「Lock 이력은 단계를 가려 받을 수 없습니다」와 「흐리게 표시된 프리셋」 설명은 현재 기능 상태를 설명한다. 원문 그대로 옮겼다.
