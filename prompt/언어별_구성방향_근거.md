# 언어별 구성 방향 근거

2026-11-09 · 적용 규칙은 `template/TRANSLATION_BRIEF.md` 「Style per language」, 디자인 고정 프롬프트 1절은 그곳을 가리킨다. 이 문서는 근거 자료의 확인 수준과 쓸 수 있는 범위만 적는다.

쓸 수 있는 자료는 있다. 다만 인쇄 매뉴얼 문체를 직접 실험한 연구는 찾지 못했고, 매뉴얼 근거로 바로 쓸 수 있는 자료는 7건이다. 보조로만 쓸 자료는 12건, 쓰지 않을 자료는 2건이다. 표는 공통 행 5개와 언어별 행 5개로 나눴고, 기계번역 논문 세 건은 보조 근거로 낮췄으며 Miehle 2016은 본문을 읽기 전까지 뺐다.

## 기존 세 인용은 어떻게 할까

Doherty 2012는 버리지 않고 보조 근거로 남긴다. 대상을 「영어 원문을 통제 언어로 쓰고 기계번역한 출력」으로 밝힌다. 「기술문서 번역 연구」라는 표현은 쓰지 않는다. 기계번역 결과를 읽는 실험이므로 사람이 옮긴 매뉴얼의 직접 근거는 아니다. 원문을 쓸 때의 규칙이 이해를 돕는다는 정도로만 쓴다.

Roturier 2006도 보조로 남긴다. 독일어 행에서만, 「가능성 수준」으로만 인용한다. 프랑스어 결과가 유의하지 않았다는 점도 함께 적는다. 기계번역 문서를 대상으로 한 연구라는 점을 표 안에 밝힌다.

Miehle 2016은 표에서 뺀다. 대화 시스템 연구이고, 확인한 자료에서 「독일 참여자의 직접성」이나 「배경 설명 선호」 결과가 나오지 않는다. PDF 본문을 열어 결과를 확인하면 「문화권별 대화 표현 차이」를 보는 보조 근거로 다시 판단한다.

## 적용하면 매뉴얼이 어떻게 달라지는가

| 항목 | 지금 | 바뀐 뒤 |
| --- | --- | --- |
| 영어 문장 분리 | 디자인 프롬프트 표는 문장 분리를 기본 규칙으로 삼지 않는다고 적었다. 번역 지침에는 그 말이 없다. 프로젝트 권은 마침표가 원문보다 15% 늘었다. | 번역 지침에 「항목은 나누지 않는다. 문장은 의미를 지킬 때만 나눈다」를 넣는다. 번역 뒤 20단어를 넘는 절차 문장 목록을 검수 기록에 남긴다. |
| 영어 용어와 항목 수 | 원문 항목 수와 묶음을 유지한다. 용어집을 재사용한다. | 바뀌지 않는다. 검수 시트에 정확성과 간결성 질문을 더한다. |
| 일본어 문체 | です・ます체, ~してください형. 근거 문장은 지금 연구 근거처럼 보인다. | 형식은 바뀌지 않는다. 근거 문장은 협회 지침을 확인한 뒤 고친다. |
| 일본어 항목 순서와 연결 | 표는 독자 책임 연구를 들어 결론을 낸다. | 순서 규칙은 그대로 둔다. 연결 표현 점검 항목을 하나 더한다. 연구는 순서 변경의 근거로 쓰지 않는다. |
| 독일어 조건과 결과 | 「조건과 결과의 관계를 명확히」라고만 적혀 있다. | 조건문을 독일어 조건문으로 옮기고 결과를 같은 문단에 두는 방법을 구체화한다. 검수에서 조건 문장과 결과 문장의 위치를 확인한다. |
| 독일어 문장 분리 | 「필요한 범위에서」라고만 적혀 있다. 기준이 없다. | 「의미가 흐려질 때」를 기준으로 쓴다. 구체 예시는 번역 검수에서 쌓는다. |
| 디자인 고정 프롬프트 54~83행 | 번역 원칙과 문체 표가 함께 있다. 레이아웃과 색 기준 문서에 번역 내용이 섞여 있다. | 문체 표를 번역 지침 한 곳으로 옮긴다. 고정 프롬프트에는 참조 한 줄만 남긴다. |
| 논문 인용 | 표 안에 세 건을 인용한다. 대상과 한계가 빠져 있다. | 자료 표 전체를 근거 문서로 옮긴다. 번역 지침에는 결론만 쓴다. |
| 검수 절차 | 글자, 띄어쓰기, 색 검사만 있다. | 여섯 항목 검수 시트를 더한다. 점수 대신 문제 여부만 적는다. |
| 독자 확인 | 없다. | 언어별로 소수에게 읽기 점검을 맡기는 방안을 제안한다. 비용이 들어 hy0909의 결정이 필요하다. |

바뀌지 않는 것도 있다. 원문 보존 규칙은 그대로 둔다. 항목 수와 순서, 경고의 강도, 조건과 정보량을 바꾸지 않는다. 한글이 한 글자도 남으면 안 된다는 규칙, 용어집, 원문 색 규칙, 번호 배지 색, 세 검사 스크립트의 기준도 그대로다. 경고 분류 명칭(필수 확인, 오해하기 쉬운 동작, 참고)도 바꾸지 않는다. 이미 만든 번역본은 지금 바뀌지 않는다. 새 규칙을 쓰면 영어 프로젝트 권의 문장 분리처럼 번역본을 다시 검토해야 할 곳이 생긴다.
