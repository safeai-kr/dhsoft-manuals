# SMART EDC 사용자 매뉴얼 디자인 가이드

템플릿 v6 · 2026-11-09 · 작성 hy0909

<callout icon="📐" color="blue_bg">
SMART EDC 사용자 매뉴얼 템플릿(화면별 분권 18권 · CRF 필드 16권 · 4개 언어)의 디자인 기준을 한 쪽에 모았습니다. 가이드와 매뉴얼은 같은 원본에서 화면용(RGB)과 인쇄용(CMYK) 두 판으로 만듭니다. 화면용은 sRGB 그대로, 인쇄용은 재단 여백 3mm를 더한 216 × 303mm에 모든 색을 DeviceCMYK로 바꿔 냅니다. 수치는 CSS px이고 pt는 0.75배입니다. 제출용 PDF 두 판은 저장소 `design-guide/` 폴더에 있습니다.
</callout>

## 1. 인쇄 사양과 쪽 구조

![본문 쪽의 구역과 재단 여백. 파선은 재단 여백 끝, 실선은 재단선, 점선은 안전 영역](IMG:spec_diagram)

| 항목 | 값 |
| --- | --- |
| 쪽 크기 | 210 × 297mm (A4). 화면용 CSS 794 × 1123px, 1px = 0.75pt |
| 재단 여백 | 사방 3mm. 인쇄 PDF는 216 × 303mm, 모서리에 재단선. 끝까지 닿는 바탕과 이미지는 여백까지 늘립니다 |
| 안전 영역 | 재단선 안쪽 5mm. 글자·번호 원은 이 안에만 둡니다. 좌우 기본 여백 56px(14.8mm)이 이를 채웁니다 |
| 두 판 제작 | 화면용(RGB)과 인쇄용(CMYK)을 같은 HTML에서 만듭니다. 화면용은 sRGB 그대로 Chrome PDF로 내고, 인쇄용은 그 PDF의 글·선·이미지를 모두 DeviceCMYK로 바꿉니다(검정 분리 K = min). 인쇄소 프로파일로 최종 확인합니다 |
| 이미지 | 화면 캡처는 2배 확대본(300dpi 기준 충족), 웨이브·로고는 원본. 캡처 안 글자는 언어별 글자 교체본을 씁니다 |
| 글꼴 | Pretendard 400 · 500 · 700 · 800 (일본어 Pretendard JP). 모두 PDF에 포함하고 외곽선으로 바꾸지 않습니다 |
| 검사 | 글자·띄어쓰기(check.py), 색(check_colors.py), 미리보기 복사(check_copy.py) 불일치 0일 때만 넘깁니다 |

## 2. 디자인 토큰 — 색

토큰마다 화면용 값(HEX·RGB)과 인쇄용 값(CMYK)을 함께 둡니다. 화면용 판은 HEX 값을, 인쇄용 판은 같은 색을 CMYK로 바꾼 값을 씁니다. 색은 뜻이 있는 자리에만 씁니다. 원본 화면에서 색으로 뜻을 나눈 곳(유의사항 글씨, 결과 설명)은 원본 값을 그대로 쓰고, 번호 원만 템플릿 파랑 #3C55EB로 통일합니다(2026-10-30 결정). CMYK는 K = min 검정 분리로 계산한 인쇄 참고값입니다.

## 4. 디자인 토큰 — 간격 · 번호 원

| 항목 | 값 |
| --- | --- |
| 쪽 크기 | 210 × 297mm (A4). CSS 794 × 1123px, 1px = 0.75pt |
| 재단 여백(인쇄) | 사방 3mm. 인쇄 PDF는 216 × 303mm, 재단선은 여백 모서리에 표시 |
| 좌우 여백 | 56px ≈ 14.8mm. 표지·목차·간지·본문·푸터 모두 같다 |
| 안전 영역 | 재단선 안쪽 5mm 안에는 글자를 두지 않는다. 좌우 여백 14.8mm와 본문 위아래 여백이 이를 채운다 |
| 본문 헤더 | 한 줄 98px(위 38 + 줄 44 + 아래 16). 제목이 길면 줄 수만큼 커지고 아래 내용이 함께 내려간다 |
| 본문 영역 | 헤더 아래끝 + 22px부터 푸터 위(쪽 아래 84px)까지 |
| 푸터 | 쪽 위 1064px, 왼쪽 상위 장 제목, 오른쪽 로고(높이 14px) + 20px + 쪽번호. 선은 긋지 않는다 |
| 모서리 | 카드·경로·캡처 틀 8px. 소제목 탭은 위 두 모서리만 8px |
| 소제목 탭 간격 | 위 40px(경로 다음은 38px), 아래 12px |
| 유의사항 카드 | 안쪽 14 / 14.7 / 15px, 카드 사이 7.33px, 제목↔본문 6px, 항목 사이 4px |
| 번호 설명 | 항목 위아래 10px, 원 23px(결과 22px), 원↔글 10px, 항목 사이 1px 선 #F1F5F9 |
| 화면 캡처 | 틀 안쪽 14 / 16 / 16px, 캡처 사이 16px, 캡처 모서리 8px, 캡션 위 10px |
| 번호 원(화면 위) | 지름 22px, 흰 테두리 2px, 숫자 11.4px 700. 글자·아이콘을 가리면 옆 빈자리로, 원끼리 지름 + 4px 이상 띄움 |
| 자간 | 한국어 10pt 초과 -3%, 영어·독일어 -1%, 일본어 0. 10pt 이하 기본값 |

### 번호 원

| 종류 | 모양 | 뜻 |
| --- | --- | --- |
| 설정 | #3C55EB 채움, 흰 숫자 | 직접 조작하는 위치 |
| 결과 | 흰 채움, #3C55EB 테두리·숫자 | 바로 위 설정으로 바뀌는 위치 |
| 참고 | #64748B 채움, 흰 숫자 | 참고 위치 |

화면 위 번호 원은 글자·아이콘·테두리를 가리지 않는 가장 가까운 빈자리로 옮기고, 같은 열의 원은 같은 x에서 시작합니다. 원끼리는 중심 거리가 지름 + 4px 이상이어야 하고 이미지 밖으로 나가지 않습니다.

## 6. 파일 구성과 제작 순서

| 파일 | 역할 |
| --- | --- |
| prompt/SMART-EDC_매뉴얼_디자인_고정프롬프트.md | 모든 디자인 규칙과 결정 기록. 바뀐 규칙은 날짜·사례와 함께 먼저 적습니다 |
| template/style.css | 표지·목차·간지·본문·표·카드의 토큰 값 |
| template/paginate.js | 쪽 나눔, 헤더 가변 높이, 표 첫 열 너비, 제목 끝 줄 보정 |
| template/build.py · make_all.sh | 분권 데이터로 HTML을 만들고 검사까지 한 번에 |
| template/img_localize.py · localize_all.sh | 번역본 캡처 글자 교체(OCR → 검수 → 번역 → 다시 그리기 → 검사) |
| tools/place_markers.py | 화면 위 번호 원 자리 잡기(가림·겹침 없이) |
| tools/widen_buttons.py · extend_cut_buttons.py | 긴 번역 글자 버튼·칩 넓히기, 잘린 버튼 완성 |
| template/check*.py | 글자·색·복사·얼룩·남은 한글 검사. 모두 불일치 0이어야 넘깁니다 |
| design-guide/make_guide.py | 이 가이드의 PDF(화면용 RGB · 인쇄용 CMYK) 생성 |

1. 원본 PDF에서 글과 색을 뽑고 고정 프롬프트의 색 표와 맞는지 확인합니다. 다르면 멈추고 묻습니다.
2. 분권 데이터를 만들고 build.py로 HTML을 만듭니다. 캡처 위 번호 원은 place_markers.py가 자리를 잡습니다.
3. 번역본은 캡처 글자를 OCR → 검수 → 번역 → 다시 그리기로 바꾸고, 한글 0 · 얼룩 0을 확인합니다.
4. Chrome으로 PDF를 만들고 check.py · check_colors.py · check_copy.py를 통과시킵니다.
5. 인쇄용은 216 × 303mm로 내고 DeviceCMYK로 바꾼 뒤 재단선·안전 영역을 눈으로 확인합니다.
